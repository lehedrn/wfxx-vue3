# 经验总结目录

本目录用于收录项目开发过程中的经验总结、技术笔记和最佳实践。

---

## 目录结构

```
docs/lessons/
├── README.md              # 本说明文档
├── 2026-04-07-脚本工具开发总结.md
├── 2026-04-07-代码生成器实践.md
└── ...
```

---

## 文件命名规范

- 文件名格式：`YYYY-MM-DD-主题名称.md`
- 示例：`2026-04-07-脚本工具开发总结.md`
- 使用下划线 `_` 连接单词，不使用空格

---

## 收录内容

1. **技术实践**：某项技术的具体实践过程
2. **问题排查**：遇到的问题和解决方案
3. **最佳实践**：总结的最佳实践和规范
4. **踩坑记录**：避免重复踩坑的经验
5. **架构决策**：重要架构决策的背景和原因

---

## 维护说明

1. 经验总结应及时记录，避免遗忘
2. 内容应结构清晰，便于他人阅读理解
3. 定期回顾和更新已有文档
