## Docker 环境配置

本项目使用 Docker 运行 MySQL 和 Redis 服务，避免本地安装的复杂性。

### MySQL 8

| 配置项 | 值 |
|--------|-----|
| 容器名称 | `mysql8` |
| 数据库名 | `ry-vue` |
| 用户名 | `root` |
| 密码 | `lihaidong` |
| 端口 | 3306（容器内） |

**启动命令**：
```bash
docker run -d \
  --name mysql8 \
  -e MYSQL_ROOT_PASSWORD=lihaidong \
  -e MYSQL_DATABASE=ry-vue \
  -p 3306:3306 \
  mysql:8.0
```

**导入数据库脚本**：
```bash
# 进入容器
docker exec -it mysql8 bash

# 导入若依基础数据脚本
mysql -u root -p ry-vue < /path/to/ry_vue.sql
mysql -u root -p ry-vue < /path/to/quartz.sql
```

### Redis 8

| 配置项 | 值 |
|--------|-----|
| 容器名称 | `redis8` |
| 密码 | `lihaidong` |
| 端口 | 6379（容器内） |

**启动命令**：
```bash
docker run -d \
  --name redis8 \
  -p 6379:6379 \
  redis:8.0 \
  --requirepass lihaidong
```

## 项目配置

### 后端数据库配置

编辑 `ruoyi-admin/src/main/resources/application-druid.yml`：

```yaml
spring:
  datasource:
    type: com.alibaba.druid.pool.DruidDataSource
    driverClassName: com.mysql.cj.jdbc.Driver
    druid:
      # 主库数据源
      master:
        url: jdbc:mysql://localhost:3306/ry-vue?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
        username: root
        password: lihaidong
```

### Redis 配置

编辑 `ruoyi-admin/src/main/resources/application.yml` 或相关配置文件：

```yaml
spring:
  redis:
    host: localhost
    port: 6379
    password: lihaidong
    database: 0
```

## 验证连接

### 验证 MySQL 连接

```bash
docker exec -it mysql8 mysql -u root -p
# 输入密码：lihaidong
```

执行 SQL 验证数据库是否存在：
```sql
USE ry-vue;
SHOW TABLES;
```

### 验证 Redis 连接

```bash
docker exec -it redis8 redis-cli -a lihaidong
```

执行命令验证：
```bash
PING
# 应返回：PONG
```

## 常见问题

### Q: Docker 容器无法启动

**A**: 检查端口是否被占用：
```bash
# 查看 3306 端口占用
lsof -i :3306

# 查看 6379 端口占用
lsof -i :6379
```

### Q: MySQL 导入脚本报错

**A**: 确保脚本文件路径正确，且脚本编码为 UTF-8。

### Q: Redis 连接拒绝

**A**: 检查密码是否正确，Redis 8 默认启用 ACL，密码认证是必需的。
