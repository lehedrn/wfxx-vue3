### 配置项详解

| 配置项 | 类型 | 默认值 | 说明 |

| `navType` | Number | 1 | 导航模式（1 左侧 2 混合 3 顶部） |
| `tagsView` | Boolean | true | 是否显示标签页导航 |
| `tagsViewPersist` | Boolean | false | 是否持久化标签页（刷新后保留） |
| `tagsIcon` | Boolean | false | 是否显示页签图标 |
| `fixedHeader` | Boolean | true | 是否固定头部（滚动时头部不动） |

## vite.config.js - Vite 构建配置

**源码**: [`vite.config.js`](../../ruoyi-ui/vite.config.js)

### 核心配置

```javascript
import { defineConfig, loadEnv } from 'vite'
import path from 'path'
import createVitePlugins from './vite/plugins'

const baseUrl = 'http://localhost:18080' // 后端接口地址

export default defineConfig(({ mode, command }) => {
  const env = loadEnv(mode, process.cwd())
  
  return {
    // 基础路径
    base: VITE_APP_ENV === 'production' ? '/' : '/',
    
    // 插件配置
    plugins: createVitePlugins(env, command === 'build'),
    
    // 路径别名
    resolve: {
      alias: {
        '~': path.resolve(__dirname, './'),      // 根目录
        '@': path.resolve(__dirname, './src')    // src 目录
      }
    },
    
    // 构建配置
    build: {
      sourcemap: command === 'build' ? false : 'inline',
      outDir: 'dist',
      chunkSizeWarningLimit: 2000,
      rollupOptions: {
        output: {
          chunkFileNames: 'static/js/[name]-[hash].js',
          entryFileNames: 'static/js/[name]-[hash].js',
          assetFileNames: 'static/[ext]/[name]-[hash].[ext]'
        }
      }
    },
    
    // 开发服务器配置
    server: {
      port: 3888,
      host: true,
      open: true,
      proxy: {
        '/dev-api': {
          target: baseUrl,
          changeOrigin: true,
          rewrite: (p) => p.replace(/^\/dev-api/, '')
        }
      }
    }
  }
})
```

### 配置说明

#### 1. 基础路径 (base)

```javascript
base: VITE_APP_ENV === 'production' ? '/' : '/'
```

- 开发环境：`/`
- 生产环境：`/`（如部署在子目录，可改为 `/admin/`）

#### 2. 路径别名 (alias)

```javascript
resolve: {
  alias: {
    '~': path.resolve(__dirname, './'),    // 根目录
    '@': path.resolve(__dirname, './src')  // src 目录
  }
}
```

**使用示例**:
```javascript
import utils from '@/utils/index.js'        // 等同于 src/utils/index.js
import config from '~/package.json'         // 等同于根目录 package.json
```

#### 3. 开发服务器代理

```javascript
server: {
  port: 3888,
  host: true,
  open: true,
  proxy: {
    '/dev-api': {
      target: 'http://localhost:18080',
      changeOrigin: true,
      rewrite: (p) => p.replace(/^\/dev-api/, '')
    }
  }
}
```

**代理规则**:
- 前端请求：`/dev-api/system/user/list`
- 代理后：`http://localhost:18080/system/user/list`

#### 4. 构建输出配置

```javascript
build: {
  outDir: 'dist',
  chunkSizeWarningLimit: 2000,
  rollupOptions: {
    output: {
      chunkFileNames: 'static/js/[name]-[hash].js',
      entryFileNames: 'static/js/[name]-[hash].js',
      assetFileNames: 'static/[ext]/[name]-[hash].[ext]'
    }
  }
}
```

**输出目录结构**:
```
dist/
├── index.html
└── static/
    ├── js/
    │   ├── index-[hash].js
    │   └── vendor-[hash].js
    └── css/
        └── index-[hash].css
```

### auto-import.js - 自动导入

**源码**: [`vite/plugins/auto-import.js`](../../ruoyi-ui/vite/plugins/auto-import.js)

```javascript
import autoImport from 'unplugin-auto-import/vite'

export default function createAutoImport() {
  return autoImport({
    imports: [
      'vue',
      'vue-router',
      'pinia'
    ],
    dts: false
  })
}
```

**自动导入的内容**:
- Vue API: `ref`, `reactive`, `computed`, `watch`, `onMounted` 等
- Vue Router: `useRouter`, `useRoute`
- Pinia: `defineStore`, `storeToRefs`

**使用示例**:
```javascript
// 无需手动导入
const count = ref(0)           // 自动导入 ref
const route = useRoute()       // 自动导入 useRoute
const router = useRouter()     // 自动导入 useRouter
```

## request.js - Axios 封装配置

**源码**: [`src/utils/request.js`](../../ruoyi-ui/src/utils/request.js)

### 核心配置

```javascript
import axios from 'axios'

const service = axios.create({
  baseURL: import.meta.env.VITE_APP_BASE_API,
  timeout: 10000
})

// 请求拦截器
service.interceptors.request.use(config => {
  // 添加 token
  const token = getToken()
  if (token) {
    config.headers['Authorization'] = 'Bearer ' + token
  }
  return config
})

// 响应拦截器
service.interceptors.response.use(response => {
  const code = response.data.code
  
  // 成功
  if (code === 200) {
    return response.data
  }
  
  // 错误处理
  Message.error(response.data.msg || '请求失败')
  return Promise.reject(new Error(response.data.msg || 'Error'))
})
```

## 布局配置

### 导航模式 (navType)

| 值 | 模式 | 说明 |
|----|------|------|
| 1 | 左侧导航 | 传统的左侧菜单布局 |
| 2 | 混合导航 | 左侧菜单 + 顶部菜单 |
| 3 | 顶部导航 | 纯顶部菜单布局 |
