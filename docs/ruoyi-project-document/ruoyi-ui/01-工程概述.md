# 工程概述

## 应用简介

**ruoyi-ui** 是若依管理系统的前端应用，基于 Vue 3 + Vite + Element Plus 构建的现代化中后台管理系统前端解决方案。

- **应用名称**: 若依管理系统
- **版本**: 3.9.2
- **作者**: 若依
- **License**: MIT

## 环境配置

### Node.js 版本要求

- Node.js 18+
- 推荐使用 pnpm 作为包管理器

### 依赖安装

```bash
cd ruoyi-ui
pnpm install
```

### 开发环境

**文件**: `.env.development`

```bash
# 页面标题
VITE_APP_TITLE = 若依管理系统

# 开发环境配置
VITE_APP_ENV = 'development'

# 若依管理系统/开发环境
VITE_APP_BASE_API = '/dev-api'
```

**说明**:
- `VITE_APP_TITLE`: 应用标题，显示在浏览器标签页
- `VITE_APP_ENV`: 环境标识（development/production/staging）
- `VITE_APP_BASE_API`: API 请求基础路径，开发环境通常使用代理

### 生产环境

**文件**: `.env.production`

```bash
# 页面标题
VITE_APP_TITLE = 若依管理系统

# 生产环境配置
VITE_APP_ENV = 'production'

# 若依管理系统/生产环境
VITE_APP_BASE_API = '/prod-api'

# 是否在打包时开启压缩，支持 gzip 和 brotli
VITE_BUILD_COMPRESS = gzip
```

## 开发命令

### 启动开发服务器

```bash
pnpm dev
# 或
npm run dev
```

**默认访问地址**: http://localhost:3888

开发服务器配置（vite.config.js）:
- 端口：3888
- 自动打开浏览器：true
- 主机：true（允许外部访问）

### 构建生产版本

```bash
pnpm build:prod
# 或
npm run build:prod
```

构建输出目录：`dist/`

### 构建预发布版本

```bash
pnpm build:stage
# 或
npm run build:stage
```

### 预览生产构建

```bash
pnpm preview
```

## 入口文件分析

### index.html

```html
<!DOCTYPE html>
<html lang="zh-cn">
  <head>
    <meta charset="utf-8" />
    <title><%= VITE_APP_TITLE %></title>
    <link rel="icon" href="/favicon.ico" />
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.js"></script>
  </body>
</html>
```

### main.js - 应用入口

```javascript
import { createApp } from 'vue'
import App from './App'
import store from './store'
import router from './router'

// Element Plus
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import locale from 'element-plus/es/locale/lang/zh-cn'

// 全局组件
import Pagination from '@/components/Pagination'
import DictTag from '@/components/DictTag'
import Editor from "@/components/Editor"

const app = createApp(App)

// 全局方法挂载
app.config.globalProperties.useDict = useDict
app.config.globalProperties.download = download

// 全局组件注册
app.component('DictTag', DictTag)
app.component('Pagination', Pagination)

app.use(router)
app.use(store)
app.use(ElementPlus, { locale })
app.mount('#app')
```
