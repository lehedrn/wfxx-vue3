# 状态管理 (Pinia)

## 概述

若依前端使用 Pinia 3.x 作为状态管理库，相比 Vuex 更简洁、类型安全、支持 Composition API。

**Store 目录结构**:

```
src/store/
├── index.js              # Store 入口
└── modules/
    ├── app.js            # 应用状态
    ├── dict.js           # 字典状态
    ├── lock.js           # 锁屏状态
    ├── permission.js     # 权限路由状态
    ├── settings.js       # 系统设置状态
    ├── tagsView.js       # 标签页状态
    └── user.js           # 用户状态
```

## user - 用户状态

**源码**: [`store/modules/user.js`](../../ruoyi-ui/src/store/modules/user.js)

### State

```javascript
state: () => ({
  token: getToken(),        // Token（从 Cookie 获取）
  id: '',                   // 用户 ID
  name: '',                 // 用户名
  nickName: '',             // 昵称
  avatar: '',               // 头像
  roles: [],                // 角色列表
  permissions: []           // 权限列表
})
```

### Actions

#### login - 用户登录

```javascript
const userStore = useUserStore()

await userStore.login({
  username: 'admin',
  password: 'admin123',
  code: '1234',
  uuid: 'abc123'
})
```

**实现**:
```javascript
login(userInfo) {
  const username = userInfo.username.trim()
  const password = userInfo.password
  const code = userInfo.code
  const uuid = userInfo.uuid
  
  return new Promise((resolve, reject) => {
    login(username, password, code, uuid).then(res => {
      setToken(res.token)
      this.token = res.token
      useLockStore().unlockScreen()
      resolve()
    }).catch(error => {
      reject(error)
    })
  })
}
```

#### getInfo - 获取用户信息

```javascript
await userStore.getInfo()
```

**返回数据**:
```javascript
{
  user: {
    userId: 1,
    userName: 'admin',
    nickName: '管理员',
    email: 'admin@ruoyi.vip',
    avatar: '/profile/avatar.jpg'
  },
  roles: ['admin'],
  permissions: ['*:*:*'],
  isDefaultModifyPwd: false,
  isPasswordExpired: false
}
```

#### logOut - 退出登录

```javascript
await userStore.logOut()
```

**实现**:
```javascript
logOut() {
  return new Promise((resolve, reject) => {
    logout(this.token).then(() => {
      this.token = ''
      this.roles = []
      this.permissions = []
      removeToken()
      resolve()
    }).catch(error => {
      reject(error)
    })
  })
}
```

### 使用示例

```vue
<script setup name="UserInfo">
import { useUserStore } from '@/store/modules/user'

const userStore = useUserStore()

// 访问 state
console.log(userStore.nickName)
console.log(userStore.avatar)

// 调用 action
await userStore.getInfo()
</script>
```

## permission - 权限路由状态

**源码**: [`store/modules/permission.js`](../../ruoyi-ui/src/store/modules/permission.js)

### State

```javascript
state: () => ({
  routes: [],             // 所有路由
  addRoutes: [],          // 动态添加的路由
  defaultRoutes: [],      // 默认路由
  topbarRouters: [],      // 顶部导航路由
  sidebarRouters: []      // 侧边栏路由
})
```

### Actions

#### generateRoutes - 生成动态路由

```javascript
const permissionStore = usePermissionStore()

const routes = await permissionStore.generateRoutes()
```

**实现**:
```javascript
generateRoutes(roles) {
  return new Promise(resolve => {
    // 向后端请求路由数据
    getRouters().then(res => {
      const sdata = JSON.parse(JSON.stringify(res.data))
      const rdata = JSON.parse(JSON.stringify(res.data))
      
      const sidebarRoutes = filterAsyncRouter(sdata)
      const rewriteRoutes = filterAsyncRouter(rdata, false, true)
      
      this.setRoutes(rewriteRoutes)
      this.setSidebarRouters(constantRoutes.concat(sidebarRoutes))
      resolve(rewriteRoutes)
    })
  })
}
```

#### filterAsyncRouter - 路由过滤

```javascript
function filterAsyncRouter(asyncRouterMap, lastRouter = false, type = false) {
  return asyncRouterMap.filter(route => {
    // 组件特殊处理
    if (route.component === 'Layout') {
      route.component = Layout
    } else if (route.component === 'ParentView') {
      route.component = ParentView
    } else {
      route.component = loadView(route.component)
    }
    
    // 递归处理子路由
    if (route.children) {
      route.children = filterAsyncRouter(route.children, route, type)
    }
    
    return true
  })
}
```

### 使用示例

```javascript
// 在 permission.js 路由守卫中
usePermissionStore().generateRoutes().then(accessRoutes => {
  accessRoutes.forEach(route => {
    router.addRoute(route)
  })
  next({ ...to, replace: true })
})
```

state: () => ({

## tagsView - 标签页状态

**源码**: [`store/modules/tagsView.js`](../../ruoyi-ui/src/store/modules/tagsView.js)

### State

```javascript
state: () => ({
  visitedViews: [],     // 访问过的标签页（持久化）
  cachedViews: []       // 缓存的标签页（keep-alive）
})
```

### Actions

#### addVisitedViews - 添加标签页

```javascript
const tagsViewStore = useTagsViewStore()

tagsViewStore.addVisitedViews({
  name: 'User',
  path: '/system/user',
  meta: { title: '用户管理', icon: 'user' }
})
```

#### closeVisitedViews - 关闭标签页

```javascript
const view = { name: 'User', path: '/system/user' }
const visitedViews = tagsViewStore.closeVisitedViews(view)
```

#### delCachedView - 删除缓存

```javascript
await tagsViewStore.delCachedView(view)
```

#### refreshVisitedViews - 刷新标签页

```javascript
await tagsViewStore.refreshVisitedViews(view)
```

### 使用示例

```vue
<script setup>
import { useTagsViewStore } from '@/store/modules/tagsView'

const tagsViewStore = useTagsViewStore()

// 添加标签
tagsViewStore.addVisitedViews(route)

// 关闭标签
tagsViewStore.closeSelectedTag(view)

// 刷新标签
tagsViewStore.refreshSelectedTag(view)

// 关闭其他
tagsViewStore.closeOthersTags(view)

// 关闭全部
tagsViewStore.closeAllTags(view)
</script>
```

## 持久化配置

部分 Store 支持持久化（刷新后保留）：

- **user.token**: 保存在 Cookie 中
- **tagsView.visitedViews**: 可选持久化（配置 `tagsViewPersist`）
- **app.size**: 保存在 Cookie 中
