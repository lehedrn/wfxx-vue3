# 通用组件

## 概述

若依前端提供了 22+ 个通用组件，覆盖分页、字典展示、文件上传、富文本编辑、菜单搜索等常用场景，组件采用 Vue 3 Composition API 编写，支持按需使用。

**组件目录结构**:

```
src/components/
├── Breadcrumb/           # 面包屑
├── Crontab/              # Cron 表达式配置
├── DictTag/              # 字典标签
├── Editor/               # 富文本编辑器
├── ExcelImportDialog/    # Excel 导入对话框
├── FileUpload/           # 文件上传
├── Hamburger/            # 汉堡菜单按钮
├── HeaderNotice/         # 头部通知
├── HeaderSearch/         # 菜单搜索
├── IconSelect/           # 图标选择器
├── ImagePreview/         # 图片预览
├── ImageUpload/          # 图片上传
├── InnerLink/            # 内链 iframe
├── Pagination/           # 分页
├── ParentView/           # 父级视图（用于二级菜单）
├── RightToolbar/         # 右侧工具栏
├── RuoYi/                # 若依扩展（文档/Git 链接）
├── Screenfull/           # 全屏切换
├── SizeSelect/           # 组件尺寸选择
├── SvgIcon/              # SVG 图标
├── TagsView/             # 标签页导航
└── TreePanel/            # 树状面板
```

## 全局注册组件

以下组件在 `main.js` 中全局注册，无需手动导入：

```javascript
// main.js
import Pagination from '@/components/Pagination'
import DictTag from '@/components/DictTag'
import Editor from "@/components/Editor"
import ImageUpload from '@/components/ImageUpload'
import FileUpload from '@/components/FileUpload'
import ImagePreview from '@/components/ImagePreview'
import RightToolbar from '@/components/RightToolbar'

app.component('Pagination', Pagination)
app.component('DictTag', DictTag)
app.component('Editor', Editor)
app.component('ImageUpload', ImageUpload)
app.component('FileUpload', FileUpload)
app.component('ImagePreview', ImagePreview)
app.component('RightToolbar', RightToolbar)
```

## Pagination - 分页组件

**源码**: [`components/Pagination/index.vue`](../../ruoyi-ui/src/components/Pagination/index.vue)

### Props

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `total` | Number | - | 总记录数（必填） |
| `page` | Number | 1 | 当前页数 |
| `limit` | Number | 20 | 每页条数 |
| `pageSizes` | Array | [10, 20, 30, 50] | 每页条数选项 |
| `pagerCount` | Number | 7 | 页码按钮数量（移动端默认 5） |
| `layout` | String | 'total, sizes, prev, pager, next, jumper' | 布局 |
| `background` | Boolean | true | 是否带背景色 |
| `autoScroll` | Boolean | true | 翻页后是否自动滚动到顶部 |
| `hidden` | Boolean | false | 是否隐藏 |

### Events

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `pagination` | `{ page, limit }` | 页码或每页条数变化时触发 |
| `update:page` | `val` | page 变化时触发（v-model 支持） |
| `update:limit` | `val` | limit 变化时触发（v-model 支持） |

### 使用示例

```vue
<template>
  <el-table :data="userList">
    <el-table-column prop="userName" label="用户名" />
  </el-table>
  
  <pagination
    v-model:page="queryParams.pageNum"
    v-model:limit="queryParams.pageSize"
    :total="total"
    @pagination="getList"
  />
</template>

<script setup>
const queryParams = ref({ pageNum: 1, pageSize: 10 })
const total = ref(0)
const userList = ref([])

const getList = async () => {
  const { rows, total: count } = await listUser(queryParams.value)
  userList.value = rows
  total.value = count
}
</script>
```

## DictTag - 字典标签组件

**源码**: [`components/DictTag/index.vue`](../../ruoyi-ui/src/components/DictTag/index.vue)

### Props

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `options` | Array | - | 字典数据（来自 useDict） |
| `value` | String/Number/Array | - | 当前值 |
| `showValue` | Boolean | true | 未匹配时是否显示原始值 |
| `separator` | String | "," | 多值分隔符 |

### 使用示例

```vue
<template>
  <el-table :data="userList">
    <el-table-column prop="status" label="状态">
      <template #default="{ row }">
        <dict-tag :options="sys_normal_disable" :value="row.status" />
      </template>
    </el-table-column>
    
    <el-table-column prop="sex" label="性别">
      <template #default="{ row }">
        <dict-tag :options="sys_user_sex" :value="row.sex" />
      </template>
    </el-table-column>
  </el-table>
</template>

<script setup>
import { useDict } from '@/utils/dict'

const { sys_normal_disable, sys_user_sex } = useDict('sys_normal_disable', 'sys_user_sex')
</script>
```

### 渲染效果

```
值：1 → <el-tag>正常</el-tag>
值：0 → <el-tag type="danger">停用</el-tag>
值：[1, 2] → <el-tag>选项 1</el-tag> <el-tag>选项 2</el-tag>
```

## RightToolbar - 右侧工具栏

**源码**: [`components/RightToolbar/index.vue`](../../ruoyi-ui/src/components/RightToolbar/index.vue)

### Props

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `showSearch` | Boolean | true | 是否显示搜索按钮 |
| `search` | Boolean | true | 是否显示搜索图标 |
| `columns` | Array/Object | {} | 显隐列配置 |
| `showColumnsType` | String | 'checkbox' | 显隐列类型（checkbox/transfer） |
| `gutter` | Number | 10 | 右外边距 |
| `storageKey` | String | "" | localStorage 键（启用列显隐记忆） |

### Events

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `update:showSearch` | `val` | 搜索状态变化 |
| `queryTable` | - | 刷新表格 |

### 使用示例

```vue
<template>
  <el-form v-show="showSearch" :model="queryParams">
    <el-form-item label="用户名" prop="userName">
      <el-input v-model="queryParams.userName" clearable @keyup.enter="handleQuery" />
    </el-form-item>
  </el-form>
  
  <el-row :gutter="10" class="mb8">
    <el-col :span="1.5">
      <el-button type="primary" icon="Plus" @click="handleAdd">新增</el-button>
    </el-col>
    <el-col :span="1.5">
      <el-button type="danger" icon="Delete" :disabled="multiple" @click="handleDelete">删除</el-button>
    </el-col>
    
    <right-toolbar
      v-model:showSearch="showSearch"
      :columns="columns"
      :storage-key="'user_columns'"
      @queryTable="getList"
    />
  </el-row>
  
  <el-table>
    <el-table-column v-for="col in columns" :key="col.key" :prop="col.prop" :label="col.label" :visible="col.visible" />
  </el-table>
</template>

<script setup>
const showSearch = ref(true)
const columns = ref([
  { key: 0, prop: 'userName', label: '用户名', visible: true },
  { key: 1, prop: 'nickName', label: '昵称', visible: true },
  { key: 2, prop: 'status', label: '状态', visible: true }
])
</script>
```

## 最佳实践

### 1. 分页组件统一使用 v-model

```vue
<!-- 推荐 -->
<pagination
  v-model:page="queryParams.pageNum"
  v-model:limit="queryParams.pageSize"
  :total="total"
  @pagination="getList"
/>

<!-- 不推荐 -->
<pagination
  :page="pageNum"
  :limit="pageSize"
  :total="total"
  @pagination="getList"
  @update:page="pageNum = $event"
  @update:limit="pageSize = $event"
/>
```

### 2. 文件上传启用拖拽排序

```vue
<file-upload
  v-model="form.attachments"
  :limit="10"
  drag
/>
```

### 3. 使用 storageKey 记忆列显隐状态

```vue
<right-toolbar
  v-model:showSearch="showSearch"
  :columns="columns"
  :storage-key="'user_columns'"
  @queryTable="getList"
/>
```

### 4. 富文本编辑器上传类型选择

```vue
<!-- 上传到服务器（推荐） -->
<editor v-model="form.content" type="url" />

<!-- Base64 嵌入（小图片适用） -->
<editor v-model="form.content" type="base64" />
```
