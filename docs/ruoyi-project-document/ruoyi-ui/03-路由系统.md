# 路由系统

## 概述

若依前端的路由系统基于 Vue Router 4.x，支持动态路由、路由守卫、权限控制等功能。

**核心文件**:
- `src/router/index.js` - 路由配置入口
- `src/permission.js` - 路由守卫

---

## 路由配置结构

### 公共路由 (constantRoutes)

**源码**: [`router/index.js`](../../ruoyi-ui/src/router/index.js#L28-L93)

公共路由是无需权限验证即可访问的路由，包括：

| 路径 | 组件 | 说明 |
|------|------|------|
| `/redirect` | layout | 重定向页面 |
| `/login` | views/login | 登录页 |
| `/register` | views/register | 注册页 |
| `/:pathMatch(.*)*` | views/error/404 | 404 页面 |
| `/401` | views/error/401 | 401 页面 |
| `/` | layout → views/index | 首页 |
| `/lock` | views/lock | 锁屏页 |
| `/user/profile` | views/system/user/profile | 个人中心 |

```javascript
export const constantRoutes = [
  {
    path: '/login',
    component: () => import('@/views/login'),
    hidden: true
  },
  {
    path: '',
    component: Layout,
    redirect: '/index',
    children: [
      {
        path: '/index',
        component: () => import('@/views/index'),
        name: 'Index',
        meta: { title: '首页', icon: 'dashboard', affix: true }
      }
    ]
  }
]
```

### 动态路由 (dynamicRoutes)

动态路由是根据用户权限从后端动态获取的路由配置。

**路由生成流程**:

```
1. 用户登录成功
2. 获取用户信息（包含角色和权限）
3. 请求后端获取菜单树
4. 将菜单树转换为路由配置
5. 使用 router.addRoute() 动态添加路由
```

## 路由配置项说明

### 路由元信息 (meta)

```javascript
{
  path: '/system/user',
  component: Layout,
  children: [{
    path: 'index',
    component: () => import('@/views/system/user/index'),
    name: 'User',
    meta: {
      title: '用户管理',           // 路由标题（侧边栏/面包屑显示）
      icon: 'user',               // 路由图标
      affix: false,               // 是否固定在标签页（不可关闭）
      noCache: false,             // 是否不被 keep-alive 缓存
      breadcrumb: true,           // 是否在面包屑中显示
      activeMenu: '/system/user', // 高亮的侧边栏菜单（用于隐藏路由）
      keepAlive: true             // 是否缓存页面组件
    }
  }]
}
```

### 常用配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `hidden` | Boolean | false | 是否在侧边栏隐藏（如登录页、404 页） |
| `alwaysShow` | Boolean | false | 是否始终显示根路由（忽略 children 数量规则） |
| `redirect` | String | - | 重定向路径（设为 `noredirect` 则不重定向） |
| `name` | String | - | 路由名称（必须填写，用于 keep-alive） |
| `meta.title` | String | - | 路由标题 |
| `meta.icon` | String | - | 路由图标（SVG 名称或 Element Plus 图标） |
| `meta.affix` | Boolean | false | 是否固定在标签页 |
| `meta.noCache` | Boolean | false | 是否不被 keep-alive 缓存 |
| `meta.breadcrumb` | Boolean | true | 是否在面包屑中显示 |
| `meta.activeMenu` | String | - | 高亮的侧边栏菜单路径 |
| `meta.keepAlive` | Boolean | false | 是否使用 keep-alive 缓存 |

## 路由守卫

**源码**: [`permission.js`](../../ruoyi-ui/src/permission.js)

### 前置守卫 (beforeEach)

```javascript
router.beforeEach((to, from, next) => {
  NProgress.start()
  
  if (getToken()) {
    // 有 token
    if (to.path === '/login') {
      // 已登录访问登录页，重定向到首页
      next({ path: '/' })
    } else if (isWhiteList(to.path)) {
      // 在白名单内，直接访问
      next()
    } else if (isLock && to.path !== '/lock') {
      // 已锁屏，重定向到锁屏页
      next({ path: '/lock' })
    } else if (!useUserStore().roles.length) {
      // 未获取用户信息，先获取
      useUserStore().getInfo().then(() => {
        // 生成动态路由
        usePermissionStore().generateRoutes().then(accessRoutes => {
          accessRoutes.forEach(route => {
            router.addRoute(route)
          })
          next({ ...to, replace: true })
        })
      })
    } else {
      // 已有用户信息和路由，直接访问
      next()
    }
  } else {
    // 无 token
    if (isWhiteList(to.path)) {
      next()
    } else {
      // 重定向到登录页
      next(`/login?redirect=${to.fullPath}`)
    }
  }
})
```

### 后置守卫 (afterEach)

```javascript
router.afterEach(() => {
  NProgress.done()  // 关闭进度条
})
```

## 动态路由机制

### 1. 后端返回菜单结构

```json
[
  {
    "path": "/system",
    "component": "Layout",
    "meta": {
      "title": "系统管理",
      "icon": "system"
    },
    "children": [
      {
        "path": "user",
        "component": "system/user/index",
        "meta": {
          "title": "用户管理",
          "icon": "user"
        }
      }
    ]
  }
]
```

### 2. 前端转换为路由配置

**源码**: `store/modules/permission.js`

```javascript
const formatRouter = (routes) => {
  return routes.map(route => {
    const routeItem = {
      path: route.path,
      component: route.component === 'Layout' ? Layout : loadView(route.component),
      meta: route.meta,
      children: route.children ? formatRouter(route.children) : []
    }
    
    if (route.name) routeItem.name = route.name
    if (route.redirect) routeItem.redirect = route.redirect
    
    return routeItem
  })
}
```

### 3. 动态添加路由

```javascript
usePermissionStore().generateRoutes().then(accessRoutes => {
  accessRoutes.forEach(route => {
    router.addRoute(route)  // 添加到 router
  })
  next({ ...to, replace: true })  // 确保 addRoutes 完成后继续导航
})
```

## 路由懒加载

所有路由组件都使用懒加载方式，提高首屏加载速度：

```javascript
// 懒加载写法
component: () => import('@/views/system/user/index')

// 等同于
component: {
  __vccOpts: true,
  setup() {
    return () => import('@/views/system/user/index')
  }
}
```

## 路由跳转方法

### 使用 router.push

```javascript
import { useRouter } from 'vue-router'

const router = useRouter()

// 字符串路径
router.push('/system/user')

// 对象形式
router.push({ path: '/system/user' })

// 带参数
router.push({ path: '/system/user', query: { id: 123 } })

// 带命名路由
router.push({ name: 'User', params: { id: 123 } })
```

### 使用 router.replace

```javascript
// 替换当前历史记录
router.replace({ path: '/system/user' })
```

### 使用 router.go

```javascript
// 前进/后退
router.go(-1)  // 后退一页
router.go(1)   // 前进一页
```

## 路由传参

### query 参数

```javascript
// 跳转
router.push({ path: '/system/user', query: { id: 123, name: 'admin' } })

// 接收
const route = useRoute()
const id = route.query.id
const name = route.query.name
```

### params 参数

```javascript
// 路由配置
{
  path: '/user/:id',
  name: 'UserDetail',
  component: () => import('@/views/user/detail')
}

// 跳转
router.push({ name: 'UserDetail', params: { id: 123 } })

// 接收
const id = route.params.id
```

## 页面缓存 (keep-alive)

### 配置缓存

```javascript
{
  path: '/system/user',
  name: 'User',  // name 必须与组件 name 一致
  component: () => import('@/views/system/user/index'),
  meta: {
    keepAlive: true  // 开启缓存
  }
}
```

### 组件配置

```vue
<script setup name="User">
import { ref, onActivated, onDeactivated } from 'vue'

// 组件数据
const formData = ref({})

// 组件被激活时执行（从缓存恢复）
onActivated(() => {
  console.log('组件激活')
})

// 组件被停用时执行（进入缓存）
onDeactivated(() => {
  console.log('组件停用')
})
</script>
```

```javascript
import { useTagsViewStore } from '@/store/modules/tagsView'

const tagsViewStore = useTagsViewStore()

// 添加标签
tagsViewStore.addVisitedViews({ 
  name: 'User', 
  path: '/system/user',
  meta: { title: '用户管理' }

// 关闭标签
tagsViewStore.closeVisitedViews(view)

tagsViewStore.delCachedView(view).then(() => {
  router.replace({ path: '/redirect' + view.path })
})
```

## 常见路由配置示例

### 一级路由

```javascript
{
  path: '/monitor',
  component: Layout,
  redirect: '/monitor/server',
  children: [
    {
      path: 'server',
      component: () => import('@/views/monitor/server'),
      name: 'Server',
      meta: { title: '服务器', icon: 'server' }
    }
  ]
}
```

```javascript

  path: '/system/dict',
```
