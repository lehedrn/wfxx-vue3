# 工具函数

## 概述

若依前端提供了丰富的工具函数，封装在 `src/utils/` 目录下，涵盖认证、字典、校验、时间格式化、数据处理等常用功能。

**目录结构**:

```
src/utils/
├── auth.js              # 认证工具（Token 管理）
├── dict.js              # 字典工具
├── request.js           # Axios 封装（见 API 接口层文档）
├── ruoyi.js             # 若依通用工具
├── validate.js          # 验证工具
├── index.js             # 通用工具函数
├── permission.js        # 权限校验
├── errorCode.js         # 错误码映射
├── dynamicTitle.js      # 动态标题
├── scroll-to.js         # 滚动工具
├── jsencrypt.js         # RSA 加密
└── theme.js             # 主题工具
```

## auth.js - 认证工具

**源码**: [`utils/auth.js`](../../ruoyi-ui/src/utils/auth.js)

基于 `js-cookie` 封装的 Token 管理工具。

### API

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `getToken()` | - | String | 获取 Token |
| `setToken(token)` | token: String | - | 设置 Token |
| `removeToken()` | - | - | 删除 Token |

### 使用示例

```javascript
import { getToken, setToken, removeToken } from '@/utils/auth'

// 登录成功后保存 Token
setToken('eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...')

// 获取 Token
const token = getToken()

// 退出登录时删除 Token
removeToken()
```

### 存储方式

Token 存储在 Cookie 中，键名为 `Admin-Token`。

## dict.js - 字典工具

**源码**: [`utils/dict.js`](../../ruoyi-ui/src/utils/dict.js)

### useDict - 获取字典数据

**参数**: `...args` - 字典类型字符串列表  
**返回值**: `ref({ dictType: [{ label, value, elTagType, elTagClass }] })`

**使用示例**:

```vue
<template>
  <el-form :model="form">
    <el-form-item label="状态">
      <el-select v-model="form.status">
        <el-option
          v-for="dict in sys_normal_disable"
          :key="dict.value"
          :label="dict.label"
          :value="dict.value"
        />
      </el-select>
    </el-form-item>
    
    <el-form-item label="性别">
      <el-radio-group v-model="form.sex">
        <el-radio
          v-for="dict in sys_user_sex"
          :key="dict.value"
          :value="dict.value"
        >{{ dict.label }}</el-radio>
      </el-radio-group>
    </el-form-item>
    
    <el-table :data="userList">
      <el-table-column prop="status" label="状态">
        <template #default="{ row }">
          <dict-tag :options="sys_normal_disable" :value="row.status" />
        </template>
      </el-table-column>
    </el-table>
  </el-form>
</template>

<script setup>
import { useDict } from '@/utils/dict'

// 加载多个字典
const { sys_normal_disable, sys_user_sex } = useDict('sys_normal_disable', 'sys_user_sex')

const form = ref({ status: '1', sex: '1' })
</script>
```

### 工作原理

1. 首先从 `useDictStore().getDict(dictType)` 检查本地缓存
2. 如果缓存不存在，调用 `getDicts(dictType)` API 从后端获取
3. 获取后存入 Pinia store 和返回的 ref 对象

## validate.js - 验证工具

**源码**: [`utils/validate.js`](../../ruoyi-ui/src/utils/validate.js)

### 常用验证方法

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `isEmpty(value)` | value: String | Boolean | 判断是否为空 |
| `isExternal(path)` | path: String | Boolean | 判断是否为外链 |
| `isHttp(url)` | url: String | Boolean | 判断是否为 http/https 链接 |
| `validEmail(email)` | email: String | Boolean | 验证邮箱格式 |
| `validURL(url)` | url: String | Boolean | 验证 URL 格式 |
| `validUsername(str)` | str: String | Boolean | 验证用户名（admin/editor） |
| `validLowerCase(str)` | str: String | Boolean | 验证是否全小写 |
| `validUpperCase(str)` | str: String | Boolean | 验证是否全大写 |
| `validAlphabets(str)` | str: String | Boolean | 验证是否全字母 |
| `isString(str)` | str: any | Boolean | 判断是否为字符串 |
| `isArray(arg)` | arg: any | Boolean | 判断是否为数组 |
| `isPathMatch(pattern, path)` | pattern: String, path: String | Boolean | 路径匹配 |

### 使用示例

```javascript
import { isEmpty, isExternal, validEmail, validURL } from '@/utils/validate'

// 空值判断
isEmpty('')           // true
isEmpty(null)         // true
isEmpty(undefined)    // true
isEmpty('  ')         // true
isEmpty('hello')      // false

// 外链判断
isExternal('https://example.com')  // true
isExternal('mailto:test@example.com')  // true
isExternal('tel:123456789')  // true
isExternal('/system/user')  // false

// 邮箱验证
validEmail('test@example.com')  // true
validEmail('invalid-email')     // false

// URL 验证
validURL('https://example.com/path?query=1')  // true
validURL('not-a-url')                         // false
```

## ruoyi.js - 若依通用工具

**源码**: [`utils/ruoyi.js`](../../ruoyi-ui/src/utils/ruoyi.js)

### 时间格式化

#### parseTime

**参数**: 
- `time`: Date/String/Number - 时间
- `pattern`: String - 格式模板（默认 `'{y}-{m}-{d} {h}:{i}:{s}'`）

**返回值**: String - 格式化后的时间字符串

**使用示例**:

```javascript
import { parseTime } from '@/utils/ruoyi'

// 默认格式
parseTime(new Date())  // "2026-04-07 12:30:45"

// 自定义格式
parseTime(new Date(), '{y}年{m}月{d}日')  // "2026 年 04 月 07 日"
parseTime(new Date(), '{y}-{m}')         // "2026-04"
parseTime(new Date(), '{h}:{i}')         // "12:30"

// 时间戳
parseTime(1680868800000)  // "2023-04-07 12:00:00"

// 字符串
parseTime('2026-04-07')   // "2026-04-07 00:00:00"
```

### 表单重置

#### resetForm

**参数**: `refName`: String - 表单 ref 名称

**使用示例**:

```vue
<template>
  <el-form ref="formRef" :model="form">
    <el-form-item label="用户名" prop="userName">
      <el-input v-model="form.userName" />
    </el-form-item>
  </el-form>
  
  <el-button @click="handleReset">重置</el-button>
</template>

<script setup>
const formRef = ref(null)
const form = ref({ userName: '' })

const handleReset = () => {
  resetForm.call({ $refs: { formRef } }, 'formRef')
  // 或
  formRef.value?.resetFields()
}
</script>
```

### 日期范围处理

#### addDateRange

**参数**:
- `params`: Object - 查询参数对象
- `dateRange`: Array - 日期范围数组 `['开始时间', '结束时间']`
- `propName`: String (可选) - 属性名前缀

**返回值**: Object - 处理后的参数对象

**使用示例**:

```javascript
import { addDateRange } from '@/utils/ruoyi'

// 基础用法
const queryParams = { pageNum: 1, pageSize: 10 }
const dateRange = ['2026-04-01', '2026-04-07']
const params = addDateRange(queryParams, dateRange)
// params: { pageNum: 1, pageSize: 10, beginTime: '2026-04-01', endTime: '2026-04-07' }

// 带前缀
const params2 = addDateRange(queryParams, dateRange, 'create')
// params2: { pageNum: 1, pageSize: 10, beginCreateTime: '2026-04-01', endCreateTime: '2026-04-07' }
```

### 字典数据回显

#### selectDictLabel

**参数**:
- `datas`: Object - 字典数据对象
- `value`: String/Number - 当前值

**返回值**: String - 字典标签文本

**使用示例**:

```javascript
import { selectDictLabel } from '@/utils/ruoyi'

const dictData = {
  '1': { label: '正常', value: '1' },
  '0': { label: '停用', value: '0' }
}

selectDictLabel(dictData, '1')  // "正常"
selectDictLabel(dictData, 0)    // "停用"
```

#### selectDictLabels

**参数**:
- `datas`: Object - 字典数据对象
- `value`: String/Array - 当前值（支持多值）
- `separator`: String (可选) - 分隔符（默认`,`）

**返回值**: String - 字典标签文本（多值）

**使用示例**:

```javascript
const dictData = {
  '1': { label: '正常', value: '1' },
  '0': { label: '停用', value: '0' }
}

// 多值字符串
selectDictLabels(dictData, '1,0')        // "正常，停用"

// 数组
selectDictLabels(dictData, ['1', '0'])   // "正常，停用"

// 自定义分隔符
selectDictLabels(dictData, '1,0', ' | ') // "正常 | 停用"
```

### 树形数据处理

#### handleTree

**参数**:
- `data`: Array - 扁平数据数组
- `id`: String (可选) - id 字段名（默认 `'id'`）
- `parentId`: String (可选) - 父节点字段名（默认 `'parentId'`）
- `children`: String (可选) - 子节点字段名（默认 `'children'`）

**返回值**: Array - 树形结构数组

**使用示例**:

```javascript
import { handleTree } from '@/utils/ruoyi'

// 扁平数据
const data = [
  { id: 1, parentId: 0, name: '总公司' },
  { id: 2, parentId: 1, name: '北京分公司' },
  { id: 3, parentId: 1, name: '上海分公司' },
  { id: 4, parentId: 2, name: '北京研发部' }
]

// 转换为树形结构
const tree = handleTree(data)
// [
//   {
//     id: 1,
//     parentId: 0,
//     name: '总公司',
//     children: [
//       { id: 2, parentId: 1, name: '北京分公司', children: [...] },
//       { id: 3, parentId: 1, name: '上海分公司', children: [] }
//     ]
//   }
// ]

// 自定义字段名
const tree2 = handleTree(data, 'deptId', 'parentDeptId', 'deptChildren')
```

### 时间格式化

#### formatDate

**参数**: `cellValue`: Date/String/Number  
**返回值**: String - `YYYY-MM-DD HH:mm:ss` 格式

**使用示例**:

```javascript
import { formatDate } from '@/utils/index'

formatDate(new Date())              // "2026-04-07 12:30:45"
formatDate('2026-04-07')            // "2026-04-07 00:00:00"
formatDate(1680868800000)           // "2023-04-07 12:00:00"
```

#### formatTime

**参数**:
- `time`: Date/String/Number - 时间
- `option`: String (可选) - 格式模板

**返回值**: String - 相对时间或格式化时间

**使用示例**:

```javascript
import { formatTime } from '@/utils/index'

// 相对时间
formatTime(Date.now() - 10000)      // "刚刚"
formatTime(Date.now() - 600000)     // "10 分钟前"
formatTime(Date.now() - 7200000)    // "2 小时前"
formatTime(Date.now() - 86400000)   // "1 天前"

// 格式化时间
formatTime(Date.now(), '{y}-{m}-{d}')  // "2026-04-07"
```

### 防抖函数

#### debounce

**参数**:
- `func`: Function - 需要防抖的函数
- `wait`: Number - 等待时间（ms）
- `immediate`: Boolean - 是否立即执行

**返回值**: Function - 防抖处理后的函数

**使用示例**:

```javascript
import { debounce } from '@/utils/index'

// 搜索输入框（延迟 500ms 执行）
const handleSearch = debounce((keyword) => {
  console.log('搜索:', keyword)
}, 500)

// 输入时触发
onInput((e) => handleSearch(e.target.value))
```

## 最佳实践

### 1. 字典使用

```vue
<!-- 推荐：使用 useDict 统一加载 -->
<script setup>
const { sys_normal_disable } = useDict('sys_normal_disable')
</script>

<!-- 不推荐：每个组件单独请求 -->
<script setup>
const dictData = ref([])
getDicts('sys_normal_disable').then(res => {
  dictData.value = res.data
})
</script>
```

### 2. 时间格式化

```javascript
// 推荐：使用 parseTime
const timeStr = parseTime(new Date(), '{y}-{m}-{d}')

// 不推荐：手动拼接
const timeStr = new Date().getFullYear() + '-' + ...
```

### 3. 树形数据转换

```javascript
// 部门树
const deptTree = handleTree(deptList, 'deptId', 'parentId', 'children')

// 菜单树
const menuTree = handleTree(menuList)
```

### 4. 防抖使用场景

```vue
<script setup>
import { debounce } from '@/utils/index'

// 搜索框输入
const handleSearch = debounce((keyword) => {
  getList(keyword)
}, 500)

// 窗口大小变化
const handleResize = debounce(() => {
  recalcLayout()
}, 200)
</script>
```
