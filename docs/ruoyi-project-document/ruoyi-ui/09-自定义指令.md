# 自定义指令

## 概述

若依前端提供了 3 个自定义指令，用于权限控制和文本复制功能，在 `src/directive/` 目录下统一管理，并通过 `main.js` 全局注册。

**目录结构**:

```
src/directive/
├── index.js                 # 指令注册入口
├── permission/
│   ├── hasRole.js           # 角色权限指令
│   └── hasPermi.js          # 操作权限指令
└── common/
    └── copyText.js          # 文本复制指令
```

---

## 全局注册

**源码**: [`directives/index.js`](../../ruoyi-ui/src/directive/index.js)

```javascript
import hasRole from './permission/hasRole'
import hasPermi from './permission/hasPermi'
import copyText from './common/copyText'

export default function directive(app){
  app.directive('hasRole', hasRole)
  app.directive('hasPermi', hasPermi)
  app.directive('copyText', copyText)
}
```

在 `main.js` 中调用：

```javascript
import directive from './directives'

const app = createApp(App)
directive(app)
```

## v-hasPermi - 操作权限指令

**源码**: [`directive/permission/hasPermi.js`](../../ruoyi-ui/src/directive/permission/hasPermi.js)

### 功能

根据用户权限标识控制元素显示/隐藏，无权限时自动移除该元素。

### 指令值

- 类型：`String[]` - 权限标识数组
- 权限匹配：只要包含任一权限即可显示
- 超级权限：`*:*:*` 拥有所有权限

### 使用示例

```vue
<template>
  <!-- 单个权限 -->
  <el-button v-hasPermi="['system:user:add']">新增用户</el-button>
  
  <!-- 多个权限（任一即可） -->
  <el-button v-hasPermi="['system:user:edit', 'system:user:add']">
    编辑/新增
  </el-button>
  
  <!-- 在组件中使用 -->
  <el-table-column label="操作">
    <template #default="{ row }">
      <el-button v-hasPermi="['system:user:edit']" @click="handleEdit(row)">
        编辑
      </el-button>
      <el-button v-hasPermi="['system:user:remove']" type="danger">
        删除
      </el-button>
    </template>
  </el-table-column>
</template>
```

### 工作原理

1. 从 `useUserStore().permissions` 获取当前用户权限列表
2. 检查权限列表中是否包含指令指定的权限标识
3. 如果不包含，调用 `el.parentNode.removeChild(el)` 移除元素

### 注意事项

- 指令值为空或不是数组时会抛出错误
- 元素被物理移除，不是隐藏（`display: none`）
- 超级管理员（拥有 `*:*:*` 权限）始终可见

## v-hasRole - 角色权限指令

**源码**: [`directive/permission/hasRole.js`](../../ruoyi-ui/src/directive/permission/hasRole.js)

### 功能

根据用户角色控制元素显示/隐藏，无对应角色时自动移除该元素。

### 指令值

- 类型：`String[]` - 角色标识数组
- 角色匹配：只要拥有任一角色即可显示
- 超级管理员：`admin` 角色拥有所有权限

### 使用示例

```vue
<template>
  <!-- 单个角色 -->
  <el-button v-hasRole="['admin']">管理员操作</el-button>
  
  <!-- 多个角色（任一即可） -->
  <el-button v-hasRole="['admin', 'manager']">
    管理/经理操作
  </el-button>
  
  <!-- 条件显示不同内容 -->
  <el-button v-hasRole="['admin']" type="danger">
    删除（仅管理员）
  </el-button>
  <el-button v-hasRole="['user']">
    普通用户操作
  </el-button>
</template>
```

### 工作原理

1. 从 `useUserStore().roles` 获取当前用户角色列表
2. 检查角色列表中是否包含指令指定的角色标识
3. 如果不包含，调用 `el.parentNode.removeChild(el)` 移除元素

### 注意事项

- 指令值为空或不是数组时会抛出错误
- `admin` 角色始终可见所有元素
- 元素被物理移除，不是隐藏

## v-copyText - 文本复制指令

**源码**: [`directive/common/copyText.js`](../../ruoyi-ui/src/directive/common/copyText.js)

### 功能

点击元素时复制指定文本到剪贴板。

### 指令值

| 模式 | 指令值 | 说明 |
|------|--------|------|
| 基础复制 | `v-copyText="要复制的文本"` | 复制指定文本 |
| 回调函数 | `v-copyText:callback="回调函数"` | 设置复制成功回调 |

### 使用示例

#### 基础用法

```vue
<template>
  <!-- 复制固定文本 -->
  <el-tag v-copyText="'复制成功'">点击复制</el-tag>
  
  <!-- 复制动态内容 -->
  <div class="invite-code">
    邀请码：<span v-copyText="inviteCode">{{ inviteCode }}</span>
    <el-icon><CopyDocument /></el-icon>
  </div>
  
  <!-- 复制链接 -->
  <el-button v-copyText="shareUrl">
    复制链接
  </el-button>
</template>

<script setup>
const inviteCode = ref('ABC123456')
const shareUrl = ref('https://example.com/share/123')
</script>
```

#### 带回调函数

```vue
<template>
  <!-- 复制成功后执行回调 -->
  <el-tag 
    v-copyText:callback="onCopy" 
    v-copyText="copyContent"
  >
    点击复制
  </el-tag>
</template>

<script setup>
const copyContent = ref('https://example.com/link')

const onCopy = (text) => {
  ElMessage.success(`已复制：${text}`)
}
</script>
```

#### 组合使用

```vue
<template>
  <div class="copy-wrapper">
    <span class="text">{{ couponCode }}</span>
    <el-button 
      size="small"
      v-copyText:callback="handleCopy" 
      v-copyText="couponCode"
    >
      复制
    </el-button>
  </div>
</template>

<script setup>
const couponCode = ref('COUPON2026')

const handleCopy = (text) => {
  ElMessage.success(`优惠券码 ${text} 已复制`)
}
</script>
```

### 工作原理

1. 创建隐藏的 `<textarea>` 元素
2. 将文本设置到 textarea 并选中
3. 调用 `document.execCommand('copy')` 执行复制
4. 恢复之前的焦点状态
5. 移除临时 textarea 元素

### 兼容性

- 使用 `execCommand('copy')` API
- 主流浏览器均支持
- 移动端 iOS/Android 支持良好

## 最佳实践

### 1. 优先使用指令

```vue
<!-- 推荐：使用指令，代码简洁 -->
<el-button v-hasPermi="['system:user:add']">新增</el-button>

<!-- 不推荐：手动判断，代码冗长 -->
<el-button v-if="userStore.permissions.includes('system:user:add')">
  新增
</el-button>
```

### 2. 权限标识集中管理

```javascript
// utils/permissions.js
export const UserPermissions = {
  ADD: 'system:user:add',
  EDIT: 'system:user:edit',
  REMOVE: 'system:user:remove',
  EXPORT: 'system:user:export'
}

// 使用
<el-button v-hasPermi="[UserPermissions.ADD]">新增</el-button>
```

### 3. 复制提示优化

```vue
<template>
  <el-tooltip content="点击复制">
    <span 
      class="copy-text"
      v-copyText:callback="onCopy"
      v-copyText="textToCopy"
    >
      {{ displayText }}
    </span>
  </el-tooltip>
</template>

<script setup>
const onCopy = () => {
  ElMessage.success('复制成功')
}
</script>

<style scoped>
.copy-text {
  cursor: pointer;
  color: #409EFF;
}
.copy-text:hover {
  text-decoration: underline;
}
</style>
```

### 4. 权限判断封装

```vue
<script setup>
import { computed } from 'vue'
import { useUserStore } from '@/store/modules/user'

const userStore = useUserStore()

// 封装常用权限判断
const canAddUser = computed(() => 
  userStore.permissions.includes('system:user:add')
)

const canExportData = computed(() =>
  userStore.permissions.includes('system:user:export') ||
  userStore.roles.includes('admin')
)
</script>

<template>
  <el-button v-if="canAddUser" @click="handleAdd">新增</el-button>
  <el-button v-if="canExportData" @click="handleExport">导出</el-button>
</template>
```

## 常见问题

### Q: 指令和 v-if 的区别？

**A**: 
- `v-hasPermi/v-hasRole`：无权限时物理移除元素
- `v-if`：条件渲染，可以手动控制条件

推荐使用指令，代码更简洁且语义化。

### Q: 如何在 JS 中判断权限？

**A**: 使用 `checkPermi` 和 `checkRole` 函数：

```javascript
import { checkPermi, checkRole } from '@/utils/permission'

if (checkPermi(['system:user:add'])) {
  // 有权限
}

if (checkRole(['admin'])) {
  // 有该角色
}
```

### Q: 复制失败怎么办？

**A**: `copyText` 指令内部已处理兼容性，返回布尔值表示是否成功。如需处理失败情况，使用回调函数：

```javascript
const onCopy = (text) => {
  // text 为复制的文本，可在此处理成功/失败逻辑
}
```
