# 权限验证流程详解

## 概述

若依系统采用 Spring Security + 自定义权限注解的方式实现权限控制，支持功能权限、角色权限和数据权限三种权限类型。

## 权限体系架构

```
┌─────────────────────────────────────────────────────────┐
│                    请求入口                              │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│           JwtAuthenticationTokenFilter                   │
│  - 验证 Token 有效性                                       │
│  - 设置 SecurityContext                                 │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│              @PreAuthorize 注解拦截                       │
│  - hasPermi('system:user:list')  功能权限               │
│  - hasRole('admin')             角色权限                │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│           PermissionService (ss)                        │
│  - hasPermi()    验证功能权限                           │
│  - hasRole()     验证角色权限                           │
│  - hasAnyPermi() 验证多个权限                          │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│           LoginUser.getPermissions()                    │
│  - 从 Redis 缓存获取用户权限集合                           │
└─────────────────────────────────────────────────────────┘
```

## 核心组件

| 组件 | 位置 | 作用 |
|------|------|------|
| `PermissionService` | `ruoyi-framework/web/service/` | 权限验证服务（@PreAuthorize 中使用） |

## 权限注解使用

### @PreAuthorize 功能权限

**语法**: `@PreAuthorize("@ss.hasPermi('权限标识')")`

```java
@RestController
@RequestMapping("/system/user")
public class SysUserController {
    
    // 单个权限验证
    @PreAuthorize("@ss.hasPermi('system:user:list')")
    @GetMapping("/list")
    public TableDataInfo list(SysUser user) {
        // ...
    }
    
    // 多个权限（满足其一即可）
    @PreAuthorize("@ss.hasAnyPermi('system:user:add', 'system:user:edit')")
    @PostMapping("/batchAdd")
    public AjaxResult batchAdd(@RequestBody List<SysUser> users) {
        // ...
    }
    
    // 反向验证（不具备该权限）
    @PreAuthorize("@ss.lacksPermi('system:user:remove')")
    @DeleteMapping("/test/{userIds}")
    public AjaxResult testDelete(@PathVariable Long[] userIds) {
        // ...
    }
}
```

### @PreAuthorize 角色权限

**语法**: `@PreAuthorize("@ss.hasRole('角色标识')")`

```java
@RestController
@RequestMapping("/system/role")
public class SysRoleController {
    
    // 角色验证
    @PreAuthorize("@ss.hasRole('admin')")
    @GetMapping("/admin")
    public AjaxResult admin() {
        // ...
    }
    
    // 多角色（满足其一即可）
    @PreAuthorize("@ss.hasAnyRoles('admin', 'user')")
    @GetMapping("/access")
    public AjaxResult access() {
        // ...
    }
    
    // 反向验证
    @PreAuthorize("@ss.lacksRole('vip')")
    @GetMapping("/free")
    public AjaxResult freeAccess() {
        // ...
    }
}
```

### @Log 操作日志

**语法**: `@Log(title = "模块名", businessType = BusinessType.XXX)`

```java
@Log(title = "用户管理", businessType = BusinessType.INSERT)
@PreAuthorize("@ss.hasPermi('system:user:add')")
@PostMapping
public AjaxResult add(@Validated @RequestBody SysUser user) {
    // ...
}
```

**业务类型枚举**:
- `BusinessType.INSERT`: 新增
- `BusinessType.UPDATE`: 修改
- `BusinessType.DELETE`: 删除
- `BusinessType.EXPORT`: 导出
- `BusinessType.IMPORT`: 导入
- `BusinessType.GRANT`: 授权
- `BusinessType.OTHER`: 其他

## 权限验证流程

### 步骤 1：权限信息加载

**源码**: [`SysPermissionService.java`](../../ruoyi-framework/src/main/java/com/ruoyi/framework/web/service/SysPermissionService.java)

```java
/**
 * 获取菜单数据权限
 */
public Set<String> getMenuPermission(SysUser user) {
    Set<String> perms = new HashSet<String>();
    
    // 1. 管理员拥有所有权限
    if (user.isAdmin()) {
        perms.add(Constants.ALL_PERMISSION); // "*:*:*"
    } else {
        // 2. 普通用户从角色获取权限
        List<SysRole> roles = user.getRoles();
        if (!CollectionUtils.isEmpty(roles)) {
            // 多角色设置 permissions 属性
            for (SysRole role : roles) {
                if (StringUtils.equals(role.getStatus(), UserConstants.ROLE_NORMAL) && !role.isAdmin()) {
                    Set<String> rolePerms = menuService.selectMenuPermsByRoleId(role.getRoleId());
                    role.setPermissions(rolePerms);
                    perms.addAll(rolePerms);
                }
            }
        } else {
            // 无角色时直接查询用户权限
            perms.addAll(menuService.selectMenuPermsByUserId(user.getUserId()));
        }
    }
    return perms;
}
```

### 步骤 2：权限验证实现

**源码**: [`PermissionService.java`](../../ruoyi-framework/src/main/java/com/ruoyi/framework/web/service/PermissionService.java)

```java
@Service("ss")  // SpringSecurity 首字母缩写
public class PermissionService
{
    /**
     * 验证用户是否具备某权限
     */
    public boolean hasPermi(String permission) {
        if (StringUtils.isEmpty(permission)) {
            return false;
        }
        
        LoginUser loginUser = SecurityUtils.getLoginUser();
        if (StringUtils.isNull(loginUser) || CollectionUtils.isEmpty(loginUser.getPermissions())) {
            return false;
        }
        
        PermissionContextHolder.setContext(permission);
        return hasPermissions(loginUser.getPermissions(), permission);
    }
    
    /**
     * 验证用户是否具有以下任意一个权限
     */
    public boolean hasAnyPermi(String permissions) {
        if (StringUtils.isEmpty(permissions)) {
            return false;
        }
        
        LoginUser loginUser = SecurityUtils.getLoginUser();
        if (StringUtils.isNull(loginUser) || CollectionUtils.isEmpty(loginUser.getPermissions())) {
            return false;
        }
        
        PermissionContextHolder.setContext(permissions);
        Set<String> authorities = loginUser.getPermissions();
        
        for (String permission : permissions.split(Constants.PERMISSION_DELIMITER)) {
            if (permission != null && hasPermissions(authorities, permission)) {
                return true;
            }
        }
        return false;
    }
    
    /**
     * 判断是否包含权限（核心方法）
     */
    private boolean hasPermissions(Set<String> permissions, String permission) {
        // 管理员拥有所有权限 "*:*:*" 或 精确匹配权限
        return permissions.contains(Constants.ALL_PERMISSION) 
            || permissions.contains(StringUtils.trim(permission));
    }
}
```

### 步骤 3：角色验证实现

```java
@Service("ss")
public class PermissionService
{
    /**
     * 判断用户是否拥有某个角色
     */
    public boolean hasRole(String role) {
        if (StringUtils.isEmpty(role)) {
            return false;
        }
        
        LoginUser loginUser = SecurityUtils.getLoginUser();
        if (StringUtils.isNull(loginUser) || CollectionUtils.isEmpty(loginUser.getUser().getRoles())) {
            return false;
        }
        
        for (SysRole sysRole : loginUser.getUser().getRoles()) {
            String roleKey = sysRole.getRoleKey();
            // 超级管理员或角色匹配
            if (Constants.SUPER_ADMIN.equals(roleKey) || roleKey.equals(StringUtils.trim(role))) {
                return true;
            }
        }
        return false;
    }
}
```

## 权限标识格式

### 功能权限标识

**格式**: `模块：业务：操作`

| 权限标识 | 说明 |
|----------|------|
| `system:user:list` | 用户管理 - 查询 |
| `system:user:add` | 用户管理 - 新增 |
| `system:user:edit` | 用户管理 - 修改 |
| `system:user:remove` | 用户管理 - 删除 |
| `system:user:export` | 用户管理 - 导出 |
| `system:user:import` | 用户管理 - 导入 |
| `system:role:list` | 角色管理 - 查询 |
| `system:menu:list` | 菜单管理 - 查询 |

### 特殊权限标识

| 标识 | 说明 | 拥有者 |
|------|------|--------|
| `*:*:*` | 所有权限 | 超级管理员（admin） |
| `system:*:*` | 系统管理模块所有权限 | - |
| `system:user:*` | 用户管理所有操作 | - |

## 数据权限

### @DataScope 注解

**源码**: `ruoyi-common/annotation/DataScope.java`

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface DataScope {
    /**
     * 部门表的别名
     */
    String deptAlias() default "";
    
    /**
     * 用户表的别名
     */
    String userAlias() default "";
    
    /**
     * 权限字符（用于多个 @DataScope 注解）
     */
    String key() default "";
}
```

### 数据权限范围

| 范围 | 值 | 说明 |
|------|-----|------|
| 全部数据权限 | 1 | 查看本部门及以下所有数据 |
| 自定义数据权限 | 2 | 查看指定的部门数据 |
| 本部门数据权限 | 3 | 仅查看本部门数据 |
| 本部门及以下数据权限 | 4 | 查看本部门及下级部门数据 |
| 仅本人数据权限 | 5 | 仅查看自己创建的数据 |

### 数据权限实现

```java
@Service
public class SysDeptService {
    
    @DataScope(deptAlias = "d", userAlias = "u")
    @Override
    public List<SysDept> selectDeptList(SysDept dept) {
        return deptMapper.selectDeptList(dept);
    }
}
```

**XML 中的 SQL 拼接**:
```xml
<select id="selectDeptList" resultMap="SysDeptResult">
    select d.* from sys_dept d
    left join sys_user u on u.dept_id = d.dept_id
    where d.del_flag = '0'
    ${dataScope}  <!-- 数据权限 SQL 片段 -->
</select>
```

### 数据权限拦截器

```java
@Aspect
@Component
public class DataScopeAspect {
    
    @Around("execution(public * com.ruoyi..service..*.*(..)) && @annotation(dataScope)")
    public Object around(ProceedingJoinPoint point, DataScope dataScope) throws Throwable {
        // 1. 获取当前登录用户
        LoginUser user = SecurityUtils.getLoginUser();
        
        // 2. 判断是否为管理员
        if (user.isAdmin()) {
            return point.proceed();  // 管理员跳过数据权限
        }
        
        // 3. 获取数据范围
        List<SysRole> roles = user.getUser().getRoles();
        String dataScopeSql = getDataScopeSql(roles, dataScope);
        
        // 4. 注入 SQL 过滤条件
        BaseContextHandler.setDataScope(dataScopeSql);
        
        return point.proceed();
    }
}
```

### BaseContextHandler

```java
public class BaseContextHandler {
    
    private static ThreadLocal<String> DATA_SCOPE = new ThreadLocal<>();
    
    public static void setDataScope(String sql) {
        DATA_SCOPE.set(sql);
    }
    
    public static String getDataScope() {
        return DATA_SCOPE.get();
    }
    
    public static void remove() {
        DATA_SCOPE.remove();
    }
}
```

## 权限异常处理

### AccessDeniedException

当用户没有访问权限时，抛出异常。

```java
@Component
public class RuoYiAccessDeniedHandler implements AccessDeniedHandler {
    
    @Override
    public void handle(HttpServletRequest request, HttpServletResponse response,
            AccessDeniedException e) throws IOException {
        response.setContentType("application/json;charset=UTF-8");
        response.setStatus(HttpServletResponse.SC_FORBIDDEN);
        response.getWriter().write("{\"code\": 403, \"msg\": \"没有操作权限\"}");
    }
}
```

### AuthenticationException

当用户未登录或 Token 无效时，抛出异常。

```java
@Component
public class RuoYiAuthenticationEntryPoint implements AuthenticationEntryPoint {
    
    @Override
    public void commence(HttpServletRequest request, HttpServletResponse response,
            AuthenticationException e) throws IOException {
        response.setContentType("application/json;charset=UTF-8");
        response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
        response.getWriter().write("{\"code\": 401, \"msg\": \"未登录或登录已过期\"}");
    }
}
```

### 3. 前端按钮权限控制

**Vue 模板**:
```vue
<template>
  <div>
    <!-- 权限控制按钮 -->
    <el-button
      v-hasPermi="['system:user:add']"
      @click="handleAdd">新增</el-button>
    
    <el-button
      v-hasPermi="['system:user:edit']"
      @click="handleEdit">修改</el-button>

      v-hasPermi="['system:user:remove']"
      @click="handleDelete">删除</el-button>
  </div>

```

**指令**:
```javascript
// permission.js
export default {
  hasPermi: {
    inserted(el, binding) {
      const { value } = binding;
      const permissions = store.getters.permissions;
      
      if (value && value instanceof Array && value.length > 0) {
        const hasPerm = permissions.some(perm => {
          return value.includes(perm);
        });
        
        if (!hasPerm) {
          el.parentNode && el.parentNode.removeChild(el);
        }
      }
    }
  }
}
```
