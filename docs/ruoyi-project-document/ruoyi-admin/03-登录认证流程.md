# 登录认证流程详解

## 概述

若依系统采用 JWT（JSON Web Token） + Redis 的方式实现分布式登录认证，支持多终端认证和自动续期。

## 认证架构

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│   客户端     │────▶│  Jwt 过滤器   │────▶│ Spring      │
│  (Vue 前端)  │     │(Token 验证)  │     │ Security    │
└─────────────┘     └──────────────┘     └─────────────┘
                           │                      │
                           ▼                      ▼
                    ┌──────────────┐     ┌─────────────┐
                    │   Redis      │     │   User      │
                    │ (Token 存储)  │     │DetailsService│
                    └──────────────┘     └─────────────┘
```

## 核心组件

| 组件 | 位置 | 作用 |
|------|------|------|
| `SysLoginService` | `ruoyi-framework/web/service/` | 登录验证核心逻辑 |
| `TokenService` | `ruoyi-framework/web/service/` | Token 创建、验证、刷新 |
| `JwtAuthenticationTokenFilter` | `ruoyi-framework/security/filter/` | JWT 请求过滤器 |
| `UserDetailsServiceImpl` | `ruoyi-framework/web/service/` | Spring Security 用户详情加载 |
| `SysPermissionService` | `ruoyi-framework/web/service/` | 权限信息加载 |

## 登录流程

### 步骤 1：获取验证码

**接口**: `GET /captchaImage`

**源码**: [`CaptchaController.java`](../../ruoyi-admin/src/main/java/com/ruoyi/web/controller/common/CaptchaController.java)

```java
@GetMapping("/captchaImage")
public AjaxResult getCode(HttpServletResponse response) {
    // 1. 生成 UUID
    String uuid = IdUtils.simpleUUID();
    String verifyKey = CacheConstants.CAPTCHA_CODE_KEY + uuid;
    
    // 2. 生成验证码（数学计算或字符）
    String captchaType = RuoYiConfig.getCaptchaType();
    if ("math".equals(captchaType)) {
        // 数学计算：5 + 3 = ?
        String capText = captchaProducerMath.createText();
        capStr = capText.substring(0, capText.lastIndexOf("@"));
        code = capText.substring(capText.lastIndexOf("@") + 1);
    }
    
    // 3. 验证码存入 Redis（10 分钟有效期）
    redisCache.setCacheObject(verifyKey, code, Constants.CAPTCHA_EXPIRATION, TimeUnit.MINUTES);
    
    // 4. 返回验证码图片和 UUID
    ajax.put("uuid", uuid);
    ajax.put("img", Base64.encode(os.toByteArray()));
}
```

### 步骤 3：登录验证核心逻辑

**源码**: [`SysLoginService.java`](../../ruoyi-framework/src/main/java/com/ruoyi/framework/web/service/SysLoginService.java)

```java
public String login(String username, String password, String code, String uuid) {
    // 1. 验证码校验
    validateCaptcha(username, code, uuid);
    
    // 2. 登录前置校验（用户名/密码非空、长度校验）
    loginPreCheck(username, password);
    
    // 3. Spring Security 用户验证
    UsernamePasswordAuthenticationToken authenticationToken = 
        new UsernamePasswordAuthenticationToken(username, password);
    AuthenticationContextHolder.setContext(authenticationToken);
    
    // 调用 AuthenticationManager.authenticate()
    // → UserDetailsServiceImpl.loadUserByUsername()
    // → 查询数据库验证密码
    Authentication authentication = authenticationManager.authenticate(authenticationToken);
    
    // 4. 记录登录日志
    LoginUser loginUser = (LoginUser) authentication.getPrincipal();
    recordLoginInfo(loginUser.getUserId());
    
    // 5. 生成 Token
    return tokenService.createToken(loginUser);
}
```

#### 3.1 验证码校验

```java
public void validateCaptcha(String username, String code, String uuid) {
    // 1. 检查是否启用验证码
    boolean captchaEnabled = configService.selectCaptchaEnabled();
    if (captchaEnabled) {
        // 2. 从 Redis 获取验证码
        String verifyKey = CacheConstants.CAPTCHA_CODE_KEY + uuid;
        String captcha = redisCache.getCacheObject(verifyKey);
        
        // 3. 验证码已过期
        if (captcha == null) {
            throw new CaptchaExpireException();
        }
        
        // 4. 删除验证码（一次性使用）
        redisCache.deleteObject(verifyKey);
        
        // 5. 验证码不匹配
        if (!code.equalsIgnoreCase(captcha)) {
            throw new CaptchaException();
        }
    }
}
```

#### 3.2 用户验证（UserDetailsServiceImpl）

```java
@Override
public UserDetails loadUserByUsername(String username) {
    // 1. 根据用户名查询用户
    SysUser user = userService.selectUserByUserName(username);
    
    // 2. 用户不存在
    if (StringUtils.isNull(user)) {
        throw new ServiceException("用户不存在");
    }
    
    // 3. 用户已删除
    if (UserStatus.DELETED.getCode().equals(user.getDelFlag())) {
        throw new ServiceException("用户已被删除");
    }
    
    // 4. 用户已停用
    if (UserStatus.DISABLE.getCode().equals(user.getStatus())) {
        throw new ServiceException("用户已停用");
    }
    
    // 5. 密码验证（密码锁定策略）
    passwordService.validate(user);
    
    // 6. 创建 LoginUser（包含用户信息和权限）
    return new LoginUser(user.getUserId(), user.getDeptId(), user, permissionService.getMenuPermission(user));
}
```

### 步骤 4：生成 Token

**源码**: [`TokenService.java`](../../ruoyi-framework/src/main/java/com/ruoyi/framework/web/service/TokenService.java)

```java
public String createToken(LoginUser loginUser) {
    // 1. 生成 fast UUID 作为 token 的唯一标识
    String token = IdUtils.fastUUID();
    loginUser.setToken(token);
    
    // 2. 设置用户代理信息（IP、地址、浏览器、操作系统）
    setUserAgent(loginUser);
    
    // 3. 刷新 Token 有效期（存入 Redis）
    refreshToken(loginUser);
    
    // 4. 生成 JWT（用于无状态验证）
    Map<String, Object> claims = new HashMap<>();
    claims.put(Constants.LOGIN_USER_KEY, token);
    claims.put(Constants.JWT_USERNAME, loginUser.getUsername());
    return createToken(claims);
}
```

## 请求验证流程

### JwtAuthenticationTokenFilter 过滤器

**源码**: [`JwtAuthenticationTokenFilter.java`](../../ruoyi-framework/src/main/java/com/ruoyi/framework/security/filter/JwtAuthenticationTokenFilter.java)

```java
@Override
protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain) {
    // 1. 从请求头获取 Token
    LoginUser loginUser = tokenService.getLoginUser(request);
    
    // 2. 验证 Token 有效性
    if (loginUser != null && SecurityUtils.getAuthentication() == null) {
        tokenService.verifyToken(loginUser);  // 检查是否过期，自动续期
        
        // 3. 设置 Spring Security 上下文
        UsernamePasswordAuthenticationToken authenticationToken = 
            new UsernamePasswordAuthenticationToken(loginUser, null, loginUser.getAuthorities());
        authenticationToken.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));
        SecurityContextHolder.getContext().setAuthentication(authenticationToken);
    }
    
    chain.doFilter(request, response);
}
```

### Token 验证与续期

```java
public void verifyToken(LoginUser loginUser) {
    // 1. 检查 Token 是否过期
    long expireTime = loginUser.getLoginTime() + (expireTime * MILLIS_MINUTE);
    long nowTime = System.currentTimeMillis();
    
    if (nowTime > expireTime) {
        throw new ServiceException("用户登录超时");
    }
    
    // 2. 自动续期（剩余时间少于 20 分钟时）
    if (expireTime - nowTime < MILLIS_MINUTE_TWENTY) {
        loginUser.setLoginTime(nowTime);
        refreshToken(loginUser);  // 重新存入 Redis，刷新有效期
    }
}
```

## 获取用户信息

**接口**: `GET /getInfo`

**源码**: [`SysLoginController.java`](../../ruoyi-admin/src/main/java/com/ruoyi/web/controller/system/SysLoginController.java)

```java
@GetMapping("getInfo")
public AjaxResult getInfo() {
    // 从 SecurityContext 获取当前登录用户
    LoginUser loginUser = SecurityUtils.getLoginUser();
    SysUser user = loginUser.getUser();
    
    // 获取角色和权限
    Set<String> roles = permissionService.getRolePermission(user);
    Set<String> permissions = permissionService.getMenuPermission(user);
    
    // 检查权限是否变化，如有变化则刷新 Token
    if (!loginUser.getPermissions().equals(permissions)) {
        loginUser.setPermissions(permissions);
        tokenService.refreshToken(loginUser);
    }
    
    // 返回用户信息
    ajax.put("user", user);
    ajax.put("roles", roles);
    ajax.put("permissions", permissions);
    ajax.put("isDefaultModifyPwd", initPasswordIsModify(user.getPwdUpdateDate()));
    ajax.put("isPasswordExpired", passwordIsExpiration(user.getPwdUpdateDate()));
}
```

## 退出登录

**接口**: `POST /logout`

```java
@PostMapping("/logout")
public AjaxResult logout() {
    // 1. 获取当前 Token
    String token = SecurityUtils.getToken();
    
    // 2. 获取登录用户
    LoginUser loginUser = SecurityUtils.getLoginUser();
    
    // 3. 删除 Redis 中的 Token
    tokenService.delLoginUser(token, loginUser.getUsername());
    
    // 4. 记录登出日志
    AsyncManager.me().execute(AsyncFactory.recordLogininfor(loginUser.getUsername(), Constants.LOGOUT, "退出登录成功"));
    
    return AjaxResult.success("退出成功");
}
```

## 密码错误锁定机制

**配置**:
```yaml
user:
  password:
    maxRetryCount: 5      # 最大错误次数
    lockTime: 10          # 锁定时间（分钟）
```

**实现逻辑**:
```java
// 密码错误时记录错误次数
AsyncManager.me().execute(AsyncFactory.recordLogininfor(username, Constants.LOGIN_FAIL, "密码错误"));

// 检查密码错误次数
public void clearPasswordLock(String username) {
    String cacheKey = CacheConstants.PWD_ERR_CNT_KEY + username;
    redisCache.deleteObject(cacheKey);
}

// 连续错误 5 次后锁定账户
public void recordPasswordError(String username) {
    String cacheKey = CacheConstants.PWD_ERR_CNT_KEY + username;
    Integer errorCount = redisCache.getCacheObject(cacheKey);
    errorCount = errorCount == null ? 1 : errorCount + 1;
    
    if (errorCount >= userConfig.getMaxRetryCount()) {
        // 锁定账户
        userService.lockUser(username, lockTime);
    } else {
        redisCache.setCacheObject(cacheKey, errorCount, lockTime, TimeUnit.MINUTES);
    }
}
```
