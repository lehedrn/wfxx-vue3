# 新建子模块操作指南

本文档描述在 RuoYi-Vue 项目中新建后端子模块的完整流程。

---

## 概述

在 Maven 多模块架构下，当需要新增业务功能时，应创建独立的子模块以保持项目结构清晰。

**适用场景**：
- 新增业务系统（如：客户管理、产品管理）
- 新增功能模块（如：消息中心、文件服务）
- 扩展现有模块功能

---

## 操作流程

### 步骤 1：创建模块目录

在项目根目录下创建新的模块目录，例如：`ruoyi-test`

```bash
ruoyi-test/
├── pom.xml
├── src/
│   ├── main/
│   │   ├── java/
│   │   └── resources/
│   └── test/
│       ├── java/
│       └── resources/
```

### 步骤 2：创建模块 pom.xml

在 `ruoyi-test` 目录下创建 `pom.xml` 文件：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <parent>
        <artifactId>ruoyi</artifactId>
        <groupId>com.ruoyi</groupId>
        <version>x.x.x</version>
    </parent>
    <modelVersion>4.0.0</modelVersion>

    <artifactId>ruoyi-test</artifactId>

    <description>
        test 系统模块
    </description>

    <dependencies>
        <!-- 通用工具 -->
        <dependency>
            <groupId>com.ruoyi</groupId>
            <artifactId>ruoyi-common</artifactId>
        </dependency>
    </dependencies>

</project>
```

### 步骤 3：根目录 pom.xml 声明

在项目根目录 `pom.xml` 中添加模块声明：

**modules 节点**中添加：
```xml
<modules>
    <!-- 其他模块... -->
    <module>ruoyi-test</module>
</modules>
```

**dependencies 节点**中添加（如果需要）：
```xml
<!-- 测试模块 -->
<dependency>
    <groupId>com.ruoyi</groupId>
    <artifactId>ruoyi-test</artifactId>
    <version>${ruoyi.version}</version>
</dependency>
```

### 步骤 4：ruoyi-admin 添加依赖

在 `ruoyi-admin/pom.xml` 的 `<dependencies>` 节点中添加：

```xml
<!-- 测试模块 -->
<dependency>
    <groupId>com.ruoyi</groupId>
    <artifactId>ruoyi-test</artifactId>
</dependency>
```

### 步骤 5：创建包结构

在 `ruoyi-test/src/main/java` 下创建包结构：

```
com/ruoyi/test/
├── controller/      # 控制器层
├── service/         # 服务层
│   └── impl/        # 服务实现
├── mapper/          # 数据访问层
├── domain/          # 实体类
└── config/          # 配置类（可选）
```

### 步骤 6：创建示例类

创建测试服务类 `TestService.java`：

```java
package com.ruoyi.test.service;

import org.springframework.stereotype.Service;

@Service
public class TestService
{
    public String helloTest()
    {
        return "hello";
    }
}
```

创建测试控制器 `TestController.java`：

```java
package com.ruoyi.test.controller;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;
import com.ruoyi.common.core.domain.AjaxResult;

@RestController
@RequestMapping("/test")
public class TestController
{
    @Autowired
    private TestService testService;

    @GetMapping("/hello")
    public AjaxResult hello()
    {
        return AjaxResult.success(testService.helloTest());
    }
}
```

### 步骤 7：配置资源文件

在 `ruoyi-test/src/main/resources` 下创建：

- `mapper/` - MyBatis XML 映射文件目录
- `application.yml` - 模块配置（可选）

### 步骤 8：测试验证

1. 重新编译项目：
```bash
scripts/build.sh -q
```

2. 启动后端服务：
```bash
scripts/run-backend.sh
```

3. 访问测试接口：
```
GET http://localhost:18080/test/hello
```

预期返回：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": "hello"
}
```

## 模块依赖关系

```
ruoyi-admin (Web 入口)
    ├── ruoyi-framework (核心框架)
    │   ├── ruoyi-common (通用工具)
    │   └── ruoyi-system (系统管理)
    ├── ruoyi-quartz (定时任务)
    ├── ruoyi-generator (代码生成)
    └── ruoyi-test (新增模块)
        └── ruoyi-common (通用工具)
```

## 命名规范

| 模块类型 | 前缀 | 示例 |
|---------|------|------|
| 系统模块 | `sys_` | `sys_user`, `sys_role` |
| 业务模块 | 自定义 | `test_`, `customer_`, `product_` |
| 示例模块 | `demo_` | `demo_student`, `demo_customer` |

---

## 注意事项

1. **版本号管理**：子模块 `pom.xml` 的 `<version>` 应与父项目保持一致
2. **依赖传递**：避免循环依赖，子模块应只依赖 `ruoyi-common`
3. **包名规范**：使用 `com.ruoyi.{模块名}` 包结构
4. **资源文件**：Mapper XML 文件放在 `src/main/resources/mapper/` 目录
5. **配置扫描**：确保 Spring 能扫描到新的包路径

## 常见问题

### Q1: IDEA 识别不到新模块？

**解决**：
1. 重新导入 Maven 项目（Reimport）
2. 重启 IDEA
3. 检查 `pom.xml` 语法是否正确

### Q2: 启动时报找不到类？

**解决**：
1. 检查 `ruoyi-admin/pom.xml` 是否添加了模块依赖
2. 检查包扫描路径是否包含新模块
3. 重新编译：`mvn clean install -DskipTests`

### Q3: 接口访问 404？

**解决**：
1. 检查 `@RequestMapping` 路径配置
2. 检查 Controller 类是否有 `@RestController` 注解
3. 检查 Spring 是否成功扫描到 Controller
