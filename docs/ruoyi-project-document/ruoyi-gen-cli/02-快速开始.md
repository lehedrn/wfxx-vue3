# ruoyi-gen-cli 快速开始

## 1. 环境要求

- **JDK**: 17 或更高版本
- **Maven**: 3.6+（用于构建项目）

## 2. 构建项目

```bash
# 进入项目目录
cd ruoyi-gen-cli

# Maven 打包
mvn clean package
```

构建成功后，在 `target/` 目录下生成 `ruoyi-gen-cli.jar` 文件。

## 3. 使用方式

### 3.1 简单模式（命令行参数）

适合快速生成，通过命令行参数指定核心配置：

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=create_tables.sql \
  --output=./generated.zip \
  --author=dev \
  --package=com.example.system \
  --prefix=sys_ \
  --web=element-plus
```

**参数说明**：

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `--sql` | 是 | DDL SQL 文件路径 | - |
| `--output` | 否 | 输出 ZIP 路径 | `./generated.zip` |
| `--author` | 否 | 作者名 | `ruoyi` |
| `--package` | 否 | 包名 | `com.ruoyi.system` |
| `--prefix` | 否 | 表前缀（自动去除） | - |
| `--web` | 否 | 前端类型 | `element-plus` |

### 3.2 配置文件模式（YAML）

适合复杂场景，通过 YAML 配置文件精细控制每张表、每个字段的生成行为：

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=create_tables.sql \
  --config=gen-config.yml \
  --output=./generated.zip
```

**配置层级**：

1. **全局配置**：默认作者、包名、模板类型等
2. **表级配置**：覆盖全局配置，指定类名、业务名等
3. **列级配置**：字段级别控制（字典类型、表单类型、查询方式等）

## 4. 快速示例

### 4.1 示例 1：单表 CRUD 生成

**步骤 1**：编写 DDL SQL 文件

```sql
-- 学生表
CREATE TABLE demo_student (
  id          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '学号',
  name        VARCHAR(64)  NOT NULL COMMENT '姓名',
  age         INT          DEFAULT 0 COMMENT '年龄',
  sex         CHAR(1)      DEFAULT '0' COMMENT '性别',
  create_time DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (id)
) COMMENT='学生信息表';
```

**步骤 2**：执行生成命令

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=student.sql \
  --output=./student.zip \
  --author=dev \
  --package=com.example.demo \
  --prefix=demo_ \
  --web=element-plus
```

**步骤 3**：解压生成的 ZIP 文件

```
student.zip/
├── domain/
│   └── DemoStudent.java
├── controller/
│   └── DemoStudentController.java
├── service/
│   ├── IDemoStudentService.java
│   └── DemoStudentServiceImpl.java
├── mapper/
│   └── DemoStudentMapper.java
└── mapper/xml/
    └── DemoStudentMapper.xml
```

### 4.2 示例 2：配置文件模式

**步骤 1**：编写 DDL SQL 文件（同上）

**步骤 2**：编写 YAML 配置文件

```yaml
# gen-config.yml

# 全局默认配置
global:
  author: dev
  packageName: com.example.demo
  moduleName: demo
  tplCategory: crud
  tplWebType: element-plus
  autoRemovePre: true
  tablePrefix: demo_

# 表级配置
tables:
  demo_student:
    className: Student
    functionName: 学生管理
    columns:
      sex:
        dictType: sys_user_sex
        htmlType: select
      status:
        dictType: sys_common_status
        htmlType: radio
```

**步骤 3**：执行生成命令

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=student.sql \
  --config=gen-config.yml \
  --output=./student.zip
```

### 4.3 示例 3：树表结构生成

**DDL SQL**：

```sql
-- 产品类别表（树形结构）
CREATE TABLE demo_product (
  id          BIGINT       NOT NULL AUTO_INCREMENT,
  name        VARCHAR(64)  NOT NULL COMMENT '类别名称',
  parent_id   BIGINT       DEFAULT 0 COMMENT '父类别 ID',
  ancestors   VARCHAR(500) DEFAULT '' COMMENT '祖级列表',
  sort        INT          DEFAULT 0 COMMENT '排序',
  PRIMARY KEY (id)
) COMMENT='产品类别表';
```

**YAML 配置**：

```yaml
global:
  author: dev
  packageName: com.example.demo
  tplCategory: tree         # 树表模板
  tplWebType: element-plus
  
tables:
  demo_product:
    className: Product
    functionName: 产品类别管理
    treeCode: parent_id     # 父 ID 字段
    treeParentCode: id      # 父级名称字段
    treeName: name          # 显示名称字段
```

### 4.4 示例 4：主子表结构生成

**DDL SQL**：

```sql
-- 客户表（主表）
CREATE TABLE demo_customer (
  id          BIGINT       NOT NULL AUTO_INCREMENT,
  name        VARCHAR(64)  NOT NULL COMMENT '客户名称',
  phone       VARCHAR(20)  DEFAULT '' COMMENT '联系电话',
  PRIMARY KEY (id)
) COMMENT='客户表';

-- 商品表（子表）
CREATE TABLE demo_goods (
  id          BIGINT       NOT NULL AUTO_INCREMENT,
  customer_id BIGINT       NOT NULL COMMENT '客户 ID',
  name        VARCHAR(64)  NOT NULL COMMENT '商品名称',
  price       DECIMAL(10,2) DEFAULT 0 COMMENT '价格',
  PRIMARY KEY (id)
) COMMENT='商品表';
```

**YAML 配置**：

```yaml
global:
  author: dev
  packageName: com.example.demo
  tplCategory: sub          # 主子表模板
  tplWebType: element-plus
  
tables:
  demo_customer:
    className: Customer
    functionName: 客户管理
    subTableName: demo_goods        # 子表表名
    subTableFkName: customer_id     # 子表关联外键
    
  demo_goods:
    className: Goods
    functionName: 商品管理
```

## 5. 配置优先级

配置覆盖顺序（优先级从高到低）：

1. **YAML 表级/列级配置**（最高优先级）
2. **命令行参数**
3. **YAML 全局配置**
4. **generator.yml 默认值**（最低优先级）

## 6. 输出说明

### 6.1 ZIP 文件结构

```
generated.zip/
├── domain/                 # 实体类
├── controller/             # Controller
├── service/                # Service 接口和实现
├── mapper/                 # Mapper 接口
└── mapper/xml/             # MyBatis XML 映射文件
```

### 6.2 生成的文件说明

| 文件 | 说明 |
|------|------|
| `Xxx.java` | 实体类（domain 层） |
| `XxxController.java` | 控制器（Web 层） |
| `IXxxService.java` | Service 接口 |
| `XxxServiceImpl.java` | Service 实现类 |
| `XxxMapper.java` | Mapper 接口 |
| `XxxMapper.xml` | MyBatis 映射文件 |
