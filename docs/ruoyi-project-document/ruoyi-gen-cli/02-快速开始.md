# ruoyi-gen-cli 快速开始

## 1. 环境要求

- **JDK**: 17 或更高版本
- **Maven**: 3.6+（用于构建项目）

## 2. 构建项目

```bash
# 进入项目目录
cd ruoyi-gen-cli

# Maven 打包
mvn clean package
```

构建成功后，在 `target/` 目录下生成 `ruoyi-gen-cli.jar` 文件。

## 3. 使用方式

### 3.1 简单模式（命令行参数）

适合快速生成，通过命令行参数指定核心配置：

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=create_tables.sql \
  --output=./generated.zip \
  --author=dev \
  --package=com.example.system \
  --prefix=sys_ \
  --web=element-plus
```

**参数说明**：

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `--sql` | 是 | DDL SQL 文件路径 | - |
| `--output` | 否 | 输出 ZIP 路径 | `./generated.zip` |
| `--author` | 否 | 作者名 | `ruoyi` |
| `--package` | 否 | 包名 | `com.ruoyi.system` |
| `--prefix` | 否 | 表前缀（自动去除） | - |
| `--web` | 否 | 前端类型 | `element-plus` |

### 3.2 配置文件模式（YAML）

适合复杂场景，通过 YAML 配置文件精细控制每张表、每个字段的生成行为：

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=create_tables.sql \
  --config=gen-config.yml \
  --output=./generated.zip
```

**配置层级**：

1. **全局配置**：默认作者、包名、模板类型等
2. **表级配置**：覆盖全局配置，指定类名、业务名等
3. **列级配置**：字段级别控制（字典类型、表单类型、查询方式等）

## 4. 快速示例

### 4.1 示例 1：单表 CRUD 生成

**步骤 1**：编写 DDL SQL 文件

```sql
-- 学生表
CREATE TABLE demo_student (
  id          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '学号',
  name        VARCHAR(64)  NOT NULL COMMENT '姓名',
  age         INT          DEFAULT 0 COMMENT '年龄',
  sex         CHAR(1)      DEFAULT '0' COMMENT '性别',
  create_time DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (id)
) COMMENT='学生信息表';
```

**步骤 2**：执行生成命令

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=student.sql \
  --output=./student.zip \
  --author=dev \
  --package=com.example.demo \
  --prefix=demo_ \
  --web=element-plus
```

**步骤 3**：解压生成的 ZIP 文件

```
student.zip/
├── domain/
│   └── DemoStudent.java
├── controller/
│   └── DemoStudentController.java
├── service/
│   ├── IDemoStudentService.java
│   └── DemoStudentServiceImpl.java
├── mapper/
│   └── DemoStudentMapper.java
└── mapper/xml/
    └── DemoStudentMapper.xml
```

### 4.2 示例 2：配置文件模式

**步骤 1**：编写 DDL SQL 文件（同上）

**步骤 2**：编写 YAML 配置文件

```yaml
# gen-config.yml

# 全局默认配置
global:
  author: dev
  packageName: com.example.demo
  moduleName: demo
  tplCategory: crud
  tplWebType: element-plus
  autoRemovePre: true
  tablePrefix: demo_

# 表级配置
tables:
  demo_student:
    className: Student
    functionName: 学生管理
    columns:
      sex:
        dictType: sys_user_sex
        htmlType: select
      status:
        dictType: sys_common_status
        htmlType: radio
```

**步骤 3**：执行生成命令

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=student.sql \
  --config=gen-config.yml \
  --output=./student.zip
```

### 4.3 示例 3：树表结构生成

**DDL SQL**：

```sql
-- 产品类别表（树形结构）
CREATE TABLE demo_product (
  id          BIGINT       NOT NULL AUTO_INCREMENT,
  name        VARCHAR(64)  NOT NULL COMMENT '类别名称',
  parent_id   BIGINT       DEFAULT 0 COMMENT '父类别 ID',
  ancestors   VARCHAR(500) DEFAULT '' COMMENT '祖级列表',
  sort        INT          DEFAULT 0 COMMENT '排序',
  PRIMARY KEY (id)
) COMMENT='产品类别表';
```

**YAML 配置**：

```yaml
global:
  author: dev
  packageName: com.example.demo
  tplCategory: tree         # 树表模板
  tplWebType: element-plus
  
tables:
  demo_product:
    className: Product
    functionName: 产品类别管理
    treeCode: id            # 树编码字段（主键）
    treeParentCode: parent_id # 树父编码字段
    treeName: name          # 树名称字段
```

**注意**：树表配置中，`treeCode` 通常是主键字段，`treeParentCode` 指向父节点，`treeName` 是显示名称。DDL 中必须包含这三个字段。

### 4.4 示例 4：主子表结构生成

**DDL SQL**：

```sql
-- 客户表（主表）
CREATE TABLE demo_customer (
  id          BIGINT       NOT NULL AUTO_INCREMENT,
  name        VARCHAR(64)  NOT NULL COMMENT '客户名称',
  phone       VARCHAR(20)  DEFAULT '' COMMENT '联系电话',
  PRIMARY KEY (id)
) COMMENT='客户表';

-- 商品表（子表）
CREATE TABLE demo_goods (
  id          BIGINT       NOT NULL AUTO_INCREMENT,
  customer_id BIGINT       NOT NULL COMMENT '客户 ID',
  name        VARCHAR(64)  NOT NULL COMMENT '商品名称',
  price       DECIMAL(10,2) DEFAULT 0 COMMENT '价格',
  PRIMARY KEY (id)
) COMMENT='商品表';
```

**YAML 配置**：

```yaml
global:
  author: dev
  packageName: com.example.demo
  tplCategory: sub          # 主子表模板
  tplWebType: element-plus
  
tables:
  demo_customer:
    className: Customer
    functionName: 客户管理
    subTableName: demo_goods        # 子表表名
    subTableFkName: customer_id     # 子表关联外键
    
  demo_goods:
    className: Goods
    functionName: 商品管理
```

**注意**：
- 主子表配置时，子表（`demo_goods`）的代码不会独立生成，而是作为主表（`demo_customer`）的一部分生成在同一个 ZIP 中
- 子表的 DDL 中必须包含外键字段（`customer_id`），且名称必须与 `subTableFkName` 一致
- 主表和子表都需要在 `tables` 中配置，但只有主表会生成完整的 CRUD 代码

## 5. 配置优先级

配置覆盖顺序（优先级从高到低）：

1. **YAML 表级/列级配置**（最高优先级）
2. **命令行参数**
3. **YAML 全局配置**
4. **generator.yml 默认值**（最低优先级）

## 6. 输出说明

### 6.1 ZIP 文件结构

生成的 ZIP 文件采用标准 Maven 项目结构：

```
{moduleName}.zip/
├── main/java/{package}/{module}/
│   ├── controller/
│   │   └── {ClassName}Controller.java        # 控制器
│   ├── domain/
│   │   ├── {ClassName}.java                  # 主表实体类
│   │   └── {SubClassName}.java               # 子表实体类（仅 sub 模板）
│   ├── service/
│   │   ├── I{ClassName}Service.java          # Service 接口
│   │   └── impl/
│   │       └── {ClassName}ServiceImpl.java   # Service 实现
│   └── mapper/
│       └── {ClassName}Mapper.java            # Mapper 接口
├── main/resources/mapper/{moduleName}/
│   └── {ClassName}Mapper.xml                 # MyBatis XML 映射文件
├── vue/api/{module}/
│   └── {businessName}.js                     # 前端 API 接口
├── vue/views/{module}/
│   └── index.vue                             # 前端页面组件
└── {businessName}Menu.sql                    # 菜单 SQL 脚本
```

**实际示例（学生管理）**：

```
student.zip/
├── main/java/com/ruoyi/demo/
│   ├── controller/StudentController.java
│   ├── domain/Student.java
│   ├── service/IStudentService.java
│   ├── service/impl/StudentServiceImpl.java
│   └── mapper/StudentMapper.java
├── main/resources/mapper/demo/StudentMapper.xml
├── vue/api/demo/student.js
├── vue/views/demo/student/index.vue
└── studentMenu.sql
```

**主子表示例（客户 - 商品）**：

```
customer.zip/
├── main/java/com/ruoyi/demo/
│   ├── controller/CustomerController.java
│   ├── domain/
│   │   ├── Customer.java                     # 主表实体
│   │   └── Goods.java                        # 子表实体
│   ├── service/ICustomerService.java
│   ├── service/impl/CustomerServiceImpl.java
│   └── mapper/CustomerMapper.java
├── main/resources/mapper/demo/CustomerMapper.xml
├── vue/api/demo/customer.js
├── vue/views/demo/customer/index.vue
└── customerMenu.sql
```

**注意**：
- 所有 Java 代码位于 `main/java/{package}/{module}/` 目录下
- MyBatis XML 映射文件位于 `main/resources/mapper/{moduleName}/` 目录下
- 前端代码包含 Vue API 和页面组件
- sub 模板生成的 ZIP 包含主表和子表的实体类，但只有主表的 Controller/Service/Mapper
- 每个模块附带一个 `Menu.sql` 文件，用于在系统中注册菜单

### 6.2 生成的文件说明

| 文件 | 说明 | 路径 |
|------|------|------|
| `{ClassName}.java` | 实体类（domain 层） | `main/java/{package}/{module}/domain/` |
| `{SubClassName}.java` | 子表实体类（仅 sub 模板） | `main/java/{package}/{module}/domain/` |
| `{ClassName}Controller.java` | 控制器（Web 层） | `main/java/{package}/{module}/controller/` |
| `I{ClassName}Service.java` | Service 接口 | `main/java/{package}/{module}/service/` |
| `{ClassName}ServiceImpl.java` | Service 实现类 | `main/java/{package}/{module}/service/impl/` |
| `{ClassName}Mapper.java` | Mapper 接口 | `main/java/{package}/{module}/mapper/` |
| `{ClassName}Mapper.xml` | MyBatis 映射文件 | `main/resources/mapper/{moduleName}/` |
| `{businessName}.js` | 前端 API 接口 | `vue/api/{module}/` |
| `index.vue` | 前端页面组件 | `vue/views/{module}/` |
| `{businessName}Menu.sql` | 菜单 SQL 脚本 | 根目录 |

## 7. SQL 和 YAML 配置核心说明

### 7.1 SQL DDL 编写要点

SQL DDL 文件是代码生成的核心输入，以下是关键要点：

**表注释**（必须）：
```sql
CREATE TABLE demo_student (
  -- ... 列定义
) COMMENT = '学生信息表';
```

**列注释**（必须）：
```sql
name        VARCHAR(30)     NOT NULL COMMENT '学生姓名',
sex         CHAR(1)         DEFAULT '0' COMMENT '性别（0 男 1 女 2 未知）',
status      CHAR(1)         DEFAULT '0' COMMENT '状态（0 正常 1 停用）',
birthday    DATETIME        COMMENT '生日',
```

**主键定义**（必须）：
```sql
-- 方式 1：列级定义
id          BIGINT          PRIMARY KEY     AUTO_INCREMENT COMMENT '编号',

-- 方式 2：表级定义
CREATE TABLE demo_student (
  id          BIGINT        NOT NULL        AUTO_INCREMENT COMMENT '编号',
  name        VARCHAR(30)   DEFAULT ''      COMMENT '学生姓名',
  PRIMARY KEY (id)
) COMMENT = '学生信息表';
```

**数值精度**：
```sql
-- Decimal 类型（价格、金额）
price       DECIMAL(10,2)   DEFAULT 0       COMMENT '价格'

-- Integer 类型（数量、年龄）
age         INT(3)          DEFAULT 0       COMMENT '年龄'
quantity    INT             DEFAULT 0       COMMENT '数量'
```

**完整示例**：
```sql
-- 学生表（单表 CRUD）
CREATE TABLE demo_student (
  id              BIGINT          NOT NULL      AUTO_INCREMENT COMMENT '编号',
  name            VARCHAR(30)     NOT NULL      COMMENT '学生姓名',
  age             INT(3)          DEFAULT 0     COMMENT '年龄',
  sex             CHAR(1)         DEFAULT '0'   COMMENT '性别（0 男 1 女 2 未知）',
  status          CHAR(1)         DEFAULT '0'   COMMENT '状态（0 正常 1 停用）',
  birthday        DATETIME                    COMMENT '生日',
  create_time     DATETIME        DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_time     DATETIME        DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (id)
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COMMENT='学生信息表';
```

### 7.2 YAML 配置结构

YAML 配置采用三层结构：

```yaml
# 第一层：全局默认配置
global:
  author: dev                          # 作者名
  packageName: com.ruoyi.demo          # 包路径
  moduleName: demo                     # 模块名（默认从 packageName 提取）
  autoRemovePre: true                  # 自动去除表前缀
  tablePrefix: demo_                   # 表前缀（多个用逗号分隔）
  tplCategory: crud                    # 模板类型：crud / tree / sub
  tplWebType: element-plus             # 前端类型：element-ui / element-plus
  parentMenuId: 4                      # 上级菜单 ID

# 第二层：表级配置（按表名）
tables:
  demo_student:
    className: Student                 # 实体类名
    functionName: 学生管理              # 功能名称（菜单显示）
    functionAuthor: dev                # 功能作者
    remark: 学生管理模块               # 实体类备注
    businessName: student              # 业务名（用于前端文件命名）
    formColNum: 1                      # 表单布局（1 单列 2 双列 3 三列）
    
    # 树表配置（仅 tplCategory=tree 时需要）
    treeCode: id                       # 树编码字段（主键）
    treeParentCode: parent_id          # 树父编码字段
    treeName: name                     # 树名称字段
    
    # 主子表配置（仅 tplCategory=sub 时需要）
    subTableName: demo_goods           # 子表表名
    subTableFkName: customer_id        # 子表关联外键字段
    
    # 第三层：列级配置（按列名）
    columns:
      name:
        columnComment: 学生姓名         # 字段描述
        javaType: String               # Java 类型
        javaField: name                # Java 属性名
        isInsert: true                 # 是否插入字段
        isEdit: true                   # 是否编辑字段
        isList: true                   # 是否列表字段
        isQuery: true                  # 是否查询字段
        isRequired: true               # 是否必填
        queryType: LIKE                # 查询方式：EQ / LIKE / BETWEEN 等
        htmlType: input                # 表单类型：input / select / radio 等
      
      sex:
        dictType: sys_user_sex         # 字典类型
        htmlType: select               # 下拉选择
        queryType: EQ                  # 等于查询
      
      status:
        dictType: sys_common_status    # 字典类型
        htmlType: radio                # 单选框
      
      birthday:
        javaType: Date                 # 日期类型
        htmlType: datetime             # 日期时间选择器
```

### 7.3 常用字典类型

| 字典类型 | 说明 | 选项值 |
|---------|------|--------|
| `sys_user_sex` | 用户性别 | 0 男 / 1 女 / 2 未知 |
| `sys_common_status` | 通用状态 | 0 正常 / 1 停用 |
| `sys_normal_disable` | 通用开关 | 0 正常 / 1 停用 |
| `sys_yes_no` | 是否 | 0 是 / 1 否 |

### 7.4 常用查询方式

| 查询方式 | 说明 | 适用场景 |
|---------|------|---------|
| `EQ` | 等于 | 精确匹配，如状态、性别 |
| `LIKE` | 模糊匹配 | 文本搜索，如姓名、描述 |
| `BETWEEN` | 范围查询 | 日期范围、数值范围 |
| `GT` / `LT` | 大于 / 小于 | 数值比较 |
