# ruoyi-gen-cli 配置说明

## 1. 配置文件结构

YAML 配置文件采用三层结构：**全局默认** → **表级配置** → **列级配置**。

```yaml
# 全局默认配置
global:
  author: ruoyi
  packageName: com.ruoyi.system
  # ...

# 表级配置（按表名）
tables:
  sys_user:
    className: User
    # ...
    # 列级配置（按列名）
    columns:
      user_name:
        dictType: sys_user_sex
        # ...
```

## 2. 全局默认配置

全局配置项对所有表生效，可被表级配置覆盖。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `author` | String | `ruoyi` | 作者名 |
| `packageName` | String | `com.ruoyi.system` | 生成包路径 |
| `moduleName` | String | 从 packageName 提取 | 模块名 |
| `autoRemovePre` | Boolean | `false` | 自动去除表前缀 |
| `tablePrefix` | String | - | 表前缀（多个逗号分隔） |
| `tplCategory` | String | `crud` | 模板类型：crud / tree / sub |
| `tplWebType` | String | `element-plus` | 前端类型：element-ui / element-plus |
| `parentMenuId` | Long | `3` | 上级菜单 ID |

**示例**：

```yaml
global:
  author: dev
  packageName: com.example.demo
  moduleName: demo
  autoRemovePre: true
  tablePrefix: demo_
  tplCategory: crud
  tplWebType: element-plus
  parentMenuId: 4
```

## 3. 表级配置

按表名配置，覆盖全局默认值。支持单表、树表、主子表三种模板类型。

### 3.1 基本信息

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `tableComment` | String | 表描述（覆盖 DDL 中的 COMMENT） |
| `className` | String | 实体类名（默认自动转换） |
| `functionAuthor` | String | 作者（覆盖全局 author） |
| `remark` | String | 备注 |

### 3.2 生成信息

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `tplCategory` | String | 模板类型：crud / tree / sub |
| `tplWebType` | String | 前端类型：element-ui / element-plus |
| `packageName` | String | 生成包路径 |
| `moduleName` | String | 模块名 |
| `businessName` | String | 业务名 |
| `functionName` | String | 功能名（菜单显示名） |
| `parentMenuId` | Long | 上级菜单 ID |
| `formColNum` | Integer | 表单布局（1-单列 2-双列 3-三列） |

### 3.3 树表配置（tplCategory=tree）

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `treeCode` | String | 树编码字段（列名） |
| `treeParentCode` | String | 树父编码字段（列名） |
| `treeName` | String | 树名称字段（列名） |

### 3.4 主子表配置（tplCategory=sub）

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `subTableName` | String | 关联子表的表名 |
| `subTableFkName` | String | 子表关联的外键名 |

**示例**：

```yaml
tables:
  demo_student:
    # 基本信息
    className: Student
    functionAuthor: dev
    remark: 学生管理模块
    
    # 生成信息
    tplCategory: crud
    tplWebType: element-plus
    packageName: com.example.demo
    moduleName: demo
    businessName: student
    functionName: 学生管理
    parentMenuId: 4
    formColNum: 2  # 双列表单
    
    # 树表配置（仅 tree 模板需要）
    treeCode: id
    treeParentCode: parent_id
    treeName: name
    
    # 主子表配置（仅 sub 模板需要）
    subTableName: demo_goods
    subTableFkName: customer_id
```

## 4. 列级配置

按列名配置，精细控制每个字段的生成行为。

| 配置项 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `columnComment` | String | 字段描述 | `学生姓名` |
| `javaType` | String | Java 类型 | `String` / `Integer` / `Long` / `Date` / `BigDecimal` |
| `javaField` | String | Java 属性名 | `userName` |
| `isInsert` | Boolean | 是否插入字段 | `true` / `false` |
| `isEdit` | Boolean | 是否编辑字段 | `true` / `false` |
| `isList` | Boolean | 是否列表字段 | `true` / `false` |
| `isQuery` | Boolean | 是否查询字段 | `true` / `false` |
| `isRequired` | Boolean | 是否必填 | `true` / `false` |
| `queryType` | String | 查询方式 | `EQ` / `LIKE` / `GT` / `LT` / `BETWEEN` |
| `htmlType` | String | 表单类型 | `input` / `select` / `radio` / `checkbox` / `datetime` |
| `dictType` | String | 字典类型 | `sys_user_sex` / `sys_common_status` |

### 4.1 Java 类型

支持的 Java 类型：

| 数据库类型 | Java 类型 |
|-----------|----------|
| `VARCHAR`, `TEXT` | `String` |
| `INT`, `INTEGER`, `SMALLINT` | `Integer` |
| `BIGINT` | `Long` |
| `DECIMAL`, `NUMERIC` | `BigDecimal` |
| `DOUBLE`, `FLOAT` | `Double` |
| `DATE`, `TIME`, `DATETIME` | `Date` |
| `TINYINT(1)`, `BIT` | `Boolean` |

### 4.2 查询方式

| 代码 | 说明 | 适用场景 |
|------|------|---------|
| `EQ` | 等于 | 精确匹配 |
| `NE` | 不等于 | 排除匹配 |
| `GT` | 大于 | 数值范围 |
| `GTE` | 大于等于 | 数值范围 |
| `LT` | 小于 | 数值范围 |
| `LTE` | 小于等于 | 数值范围 |
| `LIKE` | 模糊匹配 | 文本搜索 |
| `BETWEEN` | 范围查询 | 日期/数值范围 |

### 4.3 表单类型

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| `input` | 单行文本框 | 短文本输入 |
| `textarea` | 多行文本框 | 长文本输入 |
| `select` | 下拉选择 | 字典项选择 |
| `radio` | 单选框 | 少量选项单选 |
| `checkbox` | 复选框 | 多选项多选 |
| `datetime` | 日期时间选择 | 日期时间输入 |
| `imageUpload` | 图片上传 | 图片上传 |
| `fileUpload` | 文件上传 | 文件上传 |
| `editor` | 富文本编辑器 | 富文本内容 |

**示例**：

```yaml
columns:
  id:
    columnComment: 编号
    javaType: Long
    javaField: id
    isInsert: false
    isEdit: false
    isList: true
    isQuery: false
    
  name:
    columnComment: 学生姓名
    javaType: String
    javaField: name
    isInsert: true
    isEdit: true
    isList: true
    isQuery: true
    isRequired: true
    queryType: LIKE
    htmlType: input
    
  sex:
    columnComment: 性别（0 男 1 女 2 未知）
    javaType: String
    javaField: sex
    isInsert: true
    isEdit: true
    isList: true
    isQuery: true
    isRequired: true
    queryType: EQ
    htmlType: select
    dictType: sys_user_sex
    
  status:
    columnComment: 状态（0 正常 1 停用）
    javaType: String
    javaField: status
    isInsert: true
    isEdit: true
    isList: true
    isQuery: true
    queryType: EQ
    htmlType: radio
    dictType: sys_common_status
    
  hobby:
    columnComment: 爱好
    javaType: String
    javaField: hobby
    isInsert: true
    isEdit: true
    isList: true
    isQuery: false
    htmlType: checkbox
    dictType: user_hobby
    
  birthday:
    columnComment: 生日
    javaType: Date
    javaField: birthday
    isInsert: true
    isEdit: true
    isList: true
    isQuery: false
    htmlType: datetime
    
  balance:
    columnComment: 余额
    javaType: BigDecimal
    javaField: balance
    isInsert: true
    isEdit: true
    isList: true
    isQuery: true
    queryType: BETWEEN
    htmlType: input
```

## 5. 完整配置示例

### 5.1 单表 CRUD 配置

```yaml
global:
  author: dev
  packageName: com.example.demo
  moduleName: demo
  autoRemovePre: true
  tablePrefix: demo_
  tplCategory: crud
  tplWebType: element-plus
  parentMenuId: 4

tables:
  demo_student:
    className: Student
    functionName: 学生管理
    formColNum: 2
    columns:
      name:
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        isRequired: true
        queryType: LIKE
        
      sex:
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        htmlType: select
        dictType: sys_user_sex
        
      status:
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        htmlType: radio
        dictType: sys_common_status
```

### 5.2 树表结构配置

```yaml
global:
  author: dev
  packageName: com.example.demo
  tplCategory: tree
  tplWebType: element-plus

tables:
  demo_category:
    className: Category
    functionName: 类别管理

    treeParentCode: parent_id
    treeName: name
    columns:
      name:
        isInsert: true

        isList: true
        isQuery: false
        isRequired: true
        
      sort:
        isInsert: true
        isEdit: true
        isList: true
        isQuery: false

```

### 5.3 主子表配置

```yaml

  author: dev
  packageName: com.example.demo
  tplCategory: sub
  tplWebType: element-plus

  demo_customer:
    className: Customer
    functionName: 客户管理

        isInsert: true
        isEdit: true
        isList: true
        isQuery: true

    className: Goods

    columns:
      name:
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        
      price:
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        javaType: BigDecimal
```

## 6. 配置优先级

配置覆盖顺序（优先级从高到低）：

1. **YAML 表级/列级配置**（最高优先级）
2. **命令行参数**
3. **YAML 全局配置**
4. **generator.yml 默认值**（最低优先级）

## 7. 注意事项

1. **列名匹配**：列级配置的键名必须与 DDL 中的列名完全一致
2. **表名匹配**：表级配置的键名必须与 DDL 中的表名完全一致
3. **Java 类型**：建议显式指定复杂字段（如 BigDecimal、Date）的 Java 类型
4. **字典类型**：使用 `dictType` 前确保系统中已存在该字典
5. **主子表关联**：`subTableName` 和 `subTableFkName` 必须同时配置
