# ruoyi-gen-cli 最佳实践

## 1. 使用技巧

### 1.1 快速原型开发

对于简单的单表 CRUD，使用命令行参数快速生成：

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=user.sql \
  --output=./user.zip \
  --author=dev \
  --package=com.example.system \
  --prefix=sys_
```

### 1.2 精细控制字段行为

对于需要字典、特殊表单类型的字段，使用 YAML 配置文件：

```yaml
global:
  author: dev
  packageName: com.example.demo

tables:
  sys_user:
    columns:
      sex:
        dictType: sys_user_sex
        htmlType: select
        
      status:
        dictType: sys_common_status
        htmlType: radio
        
      role_ids:
        htmlType: checkbox
        dictType: sys_role
```

### 1.3 批量生成多表

将多个 CREATE TABLE 语句放在同一个 SQL 文件中：

```sql
-- all_tables.sql

-- 用户表
CREATE TABLE sys_user (
  user_id BIGINT NOT NULL AUTO_INCREMENT,
  user_name VARCHAR(30),
  PRIMARY KEY (user_id)
) COMMENT='用户信息表';

-- 角色表
CREATE TABLE sys_role (
  role_id BIGINT NOT NULL AUTO_INCREMENT,
  role_name VARCHAR(30),
  PRIMARY KEY (role_id)
) COMMENT='角色信息表';

-- 菜单表
CREATE TABLE sys_menu (
  menu_id BIGINT NOT NULL AUTO_INCREMENT,
  menu_name VARCHAR(50),
  PRIMARY KEY (menu_id)
) COMMENT='菜单信息表';
```

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=all_tables.sql \
  --config=gen-config.yml \
  --output=./all.zip
```

### 1.4 树表结构配置

对于树形结构，确保配置 treeCode、treeParentCode、treeName：

```yaml
tables:
  sys_dept:
    tplCategory: tree
    treeCode: dept_id
    treeParentCode: parent_id
    treeName: dept_name
```

**DDL 要求**：

```sql
CREATE TABLE sys_dept (
  dept_id BIGINT NOT NULL AUTO_INCREMENT,
  parent_id BIGINT DEFAULT 0,
  ancestors VARCHAR(500),
  dept_name VARCHAR(30),
  order_num INT,
  PRIMARY KEY (dept_id)
) COMMENT='部门表';
```

### 1.5 主子表配置

主子表需要同时配置主表和子表，并建立关联：

```yaml
tables:
  t_order:
    tplCategory: sub
    subTableName: t_order_item
    subTableFkName: order_id
    
  t_order_item:
    # 子表不需要特殊配置，但需要包含在 tables 中
```

**DDL 要求**：

```sql
-- 主表
CREATE TABLE t_order (
  order_id BIGINT NOT NULL AUTO_INCREMENT,
  order_no VARCHAR(30),
  total_amount DECIMAL(10,2),
  PRIMARY KEY (order_id)
) COMMENT='订单表';

-- 子表
CREATE TABLE t_order_item (
  item_id BIGINT NOT NULL AUTO_INCREMENT,
  order_id BIGINT NOT NULL,
  product_name VARCHAR(100),
  quantity INT,
  price DECIMAL(10,2),
  PRIMARY KEY (item_id)
) COMMENT='订单明细表';
```

## 2. 配置示例模板

### 2.1 简单 CRUD 模板

```yaml
global:
  author: dev
  packageName: com.example.demo
  moduleName: demo
  autoRemovePre: true
  tablePrefix: demo_
  tplCategory: crud
  tplWebType: element-plus
  parentMenuId: 4

tables:
  demo_student:
    className: Student
    functionName: 学生管理
    formColNum: 2  # 双列表单
    
    columns:
      # 主键通常不需要插入/编辑
      id:
        isInsert: false
        isEdit: false
        isList: true
        
      # 常用字段配置
      name:
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        isRequired: true
        queryType: LIKE
        
      # 字典字段
      sex:
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        htmlType: select
        dictType: sys_user_sex
        
      # 状态字段
      status:
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        htmlType: radio
        dictType: sys_common_status
        
      # 日期字段
      birthday:
        isInsert: true
        isEdit: true
        isList: true
        htmlType: datetime
```

## 3. 常见问题

### 3.1 表前缀去除问题

**问题**：生成的类名包含表前缀

**解决**：确保配置 autoRemovePre 和 tablePrefix

```yaml
global:
  autoRemovePre: true
  tablePrefix: sys_
```

或者使用命令行参数：

```bash
java -jar ruoyi-gen-cli.jar --sql=ddl.sql --prefix=sys_
```

### 3.2 字典不生效

**问题**：下拉选择显示不出字典值

**解决**：
1. 确保系统中已存在该字典类型
2. 检查 dictType 配置是否正确
3. 检查 htmlType 是否为 select/radio/checkbox

```yaml
columns:
  sex:
    htmlType: select      # 必须是 select/radio/checkbox
    dictType: sys_user_sex  # 必须是存在的字典
```

### 3.3 主子表不关联

**问题**：生成的代码没有主子表关联

**解决**：
1. 确保主表配置了 subTableName 和 subTableFkName
2. 确保子表也在 tables 列表中
3. 检查子表的外键字段名是否与 subTableFkName 一致

```yaml
tables:
  t_order:
    subTableName: t_order_item
    subTableFkName: order_id  # 必须与子表的外键字段名一致
    
  t_order_item:
    # 子表需要有 order_id 字段
```

### 3.4 树表无法展开

**问题**：树形结构无法正确展示

**解决**：
1. 确保配置 treeCode、treeParentCode、treeName
2. 确保 DDL 中有对应的字段
3. 确保 tplCategory 设置为 tree

```yaml
tables:
  sys_dept:
    tplCategory: tree
    treeCode: dept_id        # 主键字段
    treeParentCode: parent_id # 父 ID 字段
    treeName: dept_name       # 显示名称字段
```

### 3.5 生成字段缺失

**问题**：某些字段没有在生成的代码中出现

**解决**：
1. 检查 DDL 中该字段是否有注释（某些情况需要注释）
2. 检查列级配置中的 isInsert/isEdit/isList/isQuery 是否设置
3. 确保 javaType 配置正确

```yaml
columns:
  description:
    isInsert: true
    isEdit: true
    isList: true
    isQuery: false
    javaType: String
```

### 3.6 包名/模块名不正确

**问题**：生成的代码包名与预期不符

**解决**：
1. 检查全局 packageName 配置
2. 检查 moduleName 配置（默认从 packageName 末段提取）
3. 表级配置可以覆盖全局配置

```yaml
global:
  packageName: com.example.system
  moduleName: system  # 默认从 packageName 提取末段

tables:
  demo_student:
    packageName: com.example.demo  # 覆盖全局
    moduleName: demo
```

## 4. SQL 编写规范

### 4.1 表注释

```sql
-- 推荐：使用 COMMENT 关键字
CREATE TABLE sys_user (
  user_id BIGINT NOT NULL
) COMMENT='用户信息表';

-- 或者使用 MySQL 8.0+ 语法
CREATE TABLE sys_user COMMENT '用户信息表' (
  user_id BIGINT NOT NULL
);
```

### 4.2 列注释

```sql
CREATE TABLE sys_user (
  user_id BIGINT NOT NULL COMMENT '用户 ID',
  user_name VARCHAR(30) NOT NULL COMMENT '用户名称',
  email VARCHAR(100) DEFAULT '' COMMENT '邮箱',
  status CHAR(1) DEFAULT '0' COMMENT '状态（0 正常 1 停用）'
) COMMENT='用户信息表';
```

### 4.3 主键定义

```sql
-- 推荐：使用 PRIMARY KEY 明确指定
CREATE TABLE sys_user (
  user_id BIGINT NOT NULL AUTO_INCREMENT,
  user_name VARCHAR(30),
  PRIMARY KEY (user_id)
);

-- 或者：列级主键定义
CREATE TABLE sys_user (
  user_id BIGINT PRIMARY KEY NOT NULL AUTO_INCREMENT,
  user_name VARCHAR(30)
);
```

### 4.4 外键定义（主子表）

```sql
-- 主表
CREATE TABLE t_customer (
  customer_id BIGINT NOT NULL AUTO_INCREMENT,
  customer_name VARCHAR(100),
  PRIMARY KEY (customer_id)
);

-- 子表（需要有外键字段）
CREATE TABLE t_order (
  order_id BIGINT NOT NULL AUTO_INCREMENT,
  customer_id BIGINT NOT NULL,  -- 外键字段
  order_date DATE,
  PRIMARY KEY (order_id)
);
```

## 5. 开发建议

### 5.1 代码生成后的步骤

1. **检查生成的代码**
   - 验证实体类字段是否完整
   - 检查 Mapper XML 中的 SQL 是否正确
   - 验证 Controller 接口是否符合预期

2. **调整业务逻辑**
   - 在 Service 实现类中添加业务规则
   - 添加数据校验逻辑
   - 处理特殊业务场景

3. **完善前端页面**
   - 调整表单布局
   - 添加前端校验规则
   - 调整列表展示样式

### 5.2 代码风格统一

- 统一使用 4 空格缩进
- 类名使用大驼峰（PascalCase）
- 方法/变量使用小驼峰（camelCase）
- 常量使用全大写 + 下划线

### 5.3 版本控制

建议将生成的代码纳入 Git 管理：

```bash
# 创建新分支
git checkout -b feature/auto-generated

# 添加生成的代码
git add ruoyi-demo/

# 提交
git commit -m "feat: 代码生成器生成学生管理模块"

# 合并到开发分支
git merge --no-ff feature/auto-generated
```

## 6. 性能优化

### 6.1 批量生成

对于大量表，建议分批生成：

```bash
# 第一批：系统表
java -jar ruoyi-gen-cli.jar --sql=sys_tables.sql --config=sys-config.yml --output=./sys.zip

# 第二批：业务表
java -jar ruoyi-gen-cli.jar --sql=biz_tables.sql --config=biz-config.yml --output=./biz.zip
```

### 6.2 配置复用

将通用配置提取为公共配置文件：

```yaml
# common-config.yml
global:
  author: dev
  packageName: com.example
  autoRemovePre: true
  tplWebType: element-plus
```

