# ruoyi-gen-cli 命令参考

## 1. 命令格式

```bash
java -jar ruoyi-gen-cli.jar [选项]
```

## 2. 必填参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--sql` | DDL SQL 文件路径 | `--sql=create_tables.sql` |
| `--config` | YAML 配置文件路径 | `--config=gen-config.yml` |

**注意**：实际使用时建议同时提供 `--sql` 和 `--config` 参数，通过 YAML 配置文件精细控制代码生成行为。

## 3. 可选参数

### 3.1 输出控制

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--output` | `./generated.zip` | 输出 ZIP 文件路径 |

**示例**：

```bash
# 输出到指定文件
java -jar ruoyi-gen-cli.jar --sql=ddl.sql --output=/tmp/code.zip

# 输出到当前目录
java -jar ruoyi-gen-cli.jar --sql=ddl.sql --output=./myproject.zip
```

### 3.2 全局参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--author` | `ruoyi` | 作者名（可通过 YAML 配置） |
| `--package` | `com.ruoyi.system` | 生成包路径（可通过 YAML 配置） |
| `--prefix` | - | 表前缀（自动去除，可通过 YAML 配置） |
| `--web` | `element-plus` | 前端类型（可通过 YAML 配置） |

**示例**：

```bash
# 指定作者和包名
java -jar ruoyi-gen-cli.jar \
  --sql=ddl.sql \
  --config=gen-config.yml \
  --author=dev \
  --package=com.example.system

# 自动去除表前缀
java -jar ruoyi-gen-cli.jar \
  --sql=ddl.sql \
  --config=gen-config.yml \
  --prefix=sys_ \
  --web=element-plus
```

**注意**：命令行参数会覆盖 YAML 全局配置，但 YAML 表级/列级配置优先级最高。

## 4. 组合使用

### 4.1 配置文件模式（推荐）

推荐使用 YAML 配置文件精细控制代码生成：

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=create_tables.sql \
  --config=gen-config.yml \
  --output=./generated.zip
```

### 4.2 混合模式（配置文件 + 命令行覆盖）

命令行参数会覆盖 YAML 全局配置：

```bash
# YAML 配置为主，命令行参数覆盖 author 和 package
java -jar ruoyi-gen-cli.jar \
  --sql=create_tables.sql \
  --config=gen-config.yml \
  --output=./generated.zip \
  --author=override-author \
  --package=com.override.package
```

### 4.3 简单模式（仅命令行参数，不推荐）

仅适用于快速测试，实际项目建议使用配置文件：

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=create_tables.sql \
  --output=./generated.zip \
  --author=dev \
  --package=com.example.demo \
  --prefix=demo_ \
  --web=element-plus
```

## 5. 参数优先级

```
YAML 表级/列级配置（最高）
    ↓
命令行参数
    ↓
YAML 全局配置
    ↓
generator.yml 默认值（最低）
```

## 6. 错误处理

### 6.1 缺少必填参数

```
错误：请指定 --sql 和 --config 参数
示例：java -jar ruoyi-gen-cli.jar --sql=create_tables.sql --config=gen-config.yml
```

### 6.2 SQL 文件不存在

```
错误：SQL 文件不存在：/path/to/create_tables.sql
```

### 6.3 未找到 CREATE TABLE 语句

```
警告：未在 SQL 文件中找到 CREATE TABLE 语句
```

### 6.4 配置文件不存在

```
错误：配置文件不存在：/path/to/gen-config.yml
```

## 7. 完整命令示例

### 示例 1：生成单表代码

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=student.sql \
  --config=student.yml \
  --output=./student.zip
```

### 示例 2：生成树表代码

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=category.sql \
  --config=category-config.yml \
  --output=./category.zip
```

### 示例 3：批量生成多表代码

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=all_tables.sql \
  --config=gen-config.yml \
  --output=./all.zip
```

### 示例 4：生成主子表代码

```bash
java -jar ruoyi-gen-cli.jar \
  --sql=customer_goods.sql \
  --config=sub-table-config.yml \
  --output=./customer.zip
```
