# ruoyi-gen-cli 核心模块

## 1. 模块结构

```
ruoyi-gen-cli/src/main/java/com/ruoyi/gen/cli/
├── GenCliApplication.java    # 主入口类（Spring Boot CLI）
├── DdlParser.java            # DDL SQL 解析器
├── ConfigLoader.java         # YAML 配置加载器
├── GenTableConfig.java       # 配置模型定义
└── CodeGenerator.java        # 代码生成器
```

## 2. GenCliApplication - 主入口类

**源码**：`ruoyi-gen-cli/src/main/java/com/ruoyi/gen/cli/GenCliApplication.java`

### 2.1 核心功能

- Spring Boot CLI 应用入口
- 禁用 Web/DataSource/Redis 自动配置
- 解析命令行参数
- 加载 YAML 配置文件
- 协调 DDL 解析器和代码生成器

### 2.2 应用配置

```java
@SpringBootApplication(
    scanBasePackages = { "com.ruoyi.gen.cli", "com.ruoyi.generator.config" },
    exclude = { DataSourceAutoConfiguration.class }  // 禁用数据源自动配置
)
public class GenCliApplication implements CommandLineRunner {
    // ...
}
```

### 2.3 启动流程

```
main() → SpringApplication.run()
   ↓
run(String... args)
   ↓
1. 解析命令行参数 (--sql, --output, --config, --author, --package, --prefix, --web)
   ↓
2. 校验必填参数 (--sql 必填)
   ↓
3. 加载配置 (YAML 配置文件 → ConfigLoader.load())
   ↓
4. 应用全局配置 (ConfigLoader.applyGlobalToGenConfig())
   ↓
5. 解析 DDL (DdlParser.parse())
   ↓
6. 应用配置覆盖 (ConfigLoader.applyConfig())
   ↓
7. 生成代码 (CodeGenerator.generateToZip())
```

### 2.4 命令行参数解析

## 3. DdlParser - DDL SQL 解析器

**源码**：`ruoyi-gen-cli/src/main/java/com/ruoyi/gen/cli/DdlParser.java`

### 3.1 核心功能

- 使用 Alibaba Druid SQL Parser 解析 MySQL CREATE TABLE 语句
- 在内存中构建 `GenTable` + `GenTableColumn` 对象
- 自动识别主键、自增、NOT NULL 约束

### 3.2 解析流程

```
parse(ddlSql, operName)
   ↓
SQLUtils.parseStatements(ddlSql, JdbcConstants.MYSQL)
   ↓
遍历 SQL 语句列表
   ↓
过滤 MySqlCreateTableStatement 类型
   ↓
parseTable(createStmt, operName)
   ↓
1. 解析表名、表注释
2. 初始化默认模板类型 (crud + element-plus)
3. 使用 GenUtils.initTable() 初始化包名、类名等
4. 收集主键列名
5. 解析列定义 (parseColumn)
6. 使用 GenUtils.initColumnField() 初始化 Java 字段信息
```

### 3.3 列解析

```java
private static GenTableColumn parseColumn(SQLColumnDefinition colDef, List<String> pkColumnNames) {
    GenTableColumn column = new GenTableColumn();
    
    // 列名（去除反引号）
    column.setColumnName(cleanName(colDef.getColumnName()));
    
    // 列类型（如 varchar(100)、decimal(10,2)）
    column.setColumnType(buildColumnType(colDef.getDataType()));
    
    // 列注释
    column.setColumnComment(cleanComment(colDef.getComment().toString()));
    
    // 是否主键
    boolean isPk = pkColumnNames.contains(columnName) || colDef.isPrimaryKey();
    column.setIsPk(isPk ? "1" : "0");
    
    // 是否自增
    boolean isAutoIncrement = colDef.isAutoIncrement();
    column.setIsIncrement(isAutoIncrement ? "1" : "0");
    
    // 是否必填（NOT NULL）
    boolean isNotNull = colDef.containsNotNullConstaint();
    column.setIsRequired(isNotNull ? "1" : "0");
    
    return column;
}
```

## 4. ConfigLoader - YAML 配置加载器

**源码**：`ruoyi-gen-cli/src/main/java/com/ruoyi/gen/cli/ConfigLoader.java`

### 4.1 核心功能

- 读取 YAML 配置文件
- 三层配置覆盖：DDL 解析 → YAML 全局 → YAML 表级/列级
- 应用配置到 `GenTable` 和 `GenTableColumn` 对象

### 4.2 配置加载流程

```
load(configPath)
   ↓
Yaml.loadAs(inputStream, GenTableConfig.class)
   ↓
返回 GenTableConfig 对象

applyGlobalToGenConfig(config)
   ↓
将全局配置写入 GenConfig 静态字段
(author, packageName, autoRemovePre, tablePrefix)

applyConfig(tables, config)
   ↓
遍历 GenTable 列表
   ↓
1. 应用全局默认值 (applyGlobalDefaults)
2. 应用表级配置 (applyTableConfig)
3. 构建 options JSON (buildOptions)
4. 应用列级配置 (applyColumnConfig)
```

### 4.3 配置覆盖逻辑

```java
public static void applyConfig(List<GenTable> tables, GenTableConfig config) {
    for (GenTable table : tables) {
        // 第一层：全局默认
        applyGlobalDefaults(table, g);
        
        // 第二层：表级覆盖
        GenTableConfig.TableConfig tc = tableConfigs.get(table.getTableName());
        if (tc != null) {
            applyTableConfig(table, tc);
        }
        
        // 构建 options JSON（树表/主子表/parentMenuId）
        buildOptions(table, g, tc);
        
        // 第三层：列级覆盖
        Map<String, GenTableConfig.ColumnConfig> colConfigs = tc.getColumns();
        if (colConfigs != null) {
            for (GenTableColumn column : table.getColumns()) {
                GenTableConfig.ColumnConfig cc = colConfigs.get(column.getColumnName());
                if (cc != null) {
                    applyColumnConfig(column, cc);
                }
            }
        }
    }
}
```

### 4.4 列级配置应用

```java
private static void applyColumnConfig(GenTableColumn column, GenTableConfig.ColumnConfig cc) {
    if (StringUtils.isNotEmpty(cc.getColumnComment())) {
        column.setColumnComment(cc.getColumnComment());
    }
    if (StringUtils.isNotEmpty(cc.getJavaType())) {
        column.setJavaType(cc.getJavaType());  // String/Integer/Long/Date/BigDecimal
    }
    if (cc.getIsInsert() != null) {
        column.setIsInsert(cc.getIsInsert() ? "1" : "0");
    }
    if (cc.getIsEdit() != null) {
        column.setIsEdit(cc.getIsEdit() ? "1" : "0");
    }
    if (cc.getHtmlType() != null) {
        column.setHtmlType(cc.getHtmlType());  // input/select/radio/checkbox/datetime
    }
    if (cc.getDictType() != null) {
        column.setDictType(cc.getDictType());  // sys_user_sex/sys_common_status
    }
    // ... 其他字段
}
```

## 5. CodeGenerator - 代码生成器

**源码**：`ruoyi-gen-cli/src/main/java/com/ruoyi/gen/cli/CodeGenerator.java`

### 5.1 核心功能

- 复用 ruoyi-generator 的 Velocity 模板引擎
- 建立主子表关联关系
- 生成 ZIP 文件输出

### 5.2 生成流程

```
generateToZip(tables, outputPath)
   ↓
1. 建立主子表关联 (linkSubTables)
   - 遍历所有表，查找 subTableName 配置
   - 从 tables 列表中查找对应的子表对象
   - 设置 table.setSubTable(subTable)
   
2. 创建 ZipOutputStream
   
3. 遍历表列表（跳过子表）
   ↓
   generateTable(table, zip)
   ↓
   a. 设置主键列 (setPkColumn)
   b. 初始化 Velocity (VelocityInitializer.initVelocity())
   c. 构建模板上下文 (VelocityUtils.prepareContext(table))
   d. 获取模板列表 (VelocityUtils.getTemplateList())
   e. 渲染每个模板并写入 ZIP
   
4. 写入文件
```

### 5.3 模板渲染

```java
private static void generateTable(GenTable table, ZipOutputStream zip) {
    // 设置主键列
    setPkColumn(table);
    
    // 初始化 Velocity
    VelocityInitializer.initVelocity();
    
    // 构建模板上下文
    VelocityContext context = VelocityUtils.prepareContext(table);
    
    // 获取模板列表
    List<String> templates = VelocityUtils.getTemplateList(
        table.getTplCategory(), 
        table.getTplWebType()
    );
    
    // 渲染每个模板
    for (String template : templates) {
        StringWriter sw = new StringWriter();
        Template tpl = Velocity.getTemplate(template, Constants.UTF8);
        tpl.merge(context, sw);
        
        // 获取文件名并写入 ZIP
        String fileName = VelocityUtils.getFileName(template, table);
        zip.putNextEntry(new ZipEntry(fileName));
        IOUtils.write(sw.toString(), zip, Constants.UTF8);
        zip.closeEntry();
    }
}
```

### 5.4 主子表关联

```java
private static void linkSubTables(List<GenTable> tables) {
    for (GenTable table : tables) {
        String subTableName = table.getSubTableName();
        if (subTableName != null && !subTableName.isEmpty()) {
            // 从 tables 列表中查找子表
            for (GenTable subTable : tables) {
                if (subTable.getTableName().equals(subTableName)) {
                    table.setSubTable(subTable);
                    break;
                }
            }
        }
    }
}
```

## 6. GenTableConfig - 配置模型

**源码**：`ruoyi-gen-cli/src/main/java/com/ruoyi/gen/cli/GenTableConfig.java`

### 6.1 三层配置结构

```
GenTableConfig
├── GlobalConfig          # 全局默认配置
│   ├── author            # 作者名
│   ├── packageName       # 包路径
│   ├── moduleName        # 模块名
│   ├── autoRemovePre     # 自动去前缀
│   ├── tablePrefix       # 表前缀
│   ├── tplCategory       # 模板类型
│   ├── tplWebType        # 前端类型
│   └── parentMenuId      # 上级菜单 ID
├── Map<String, TableConfig> tables  # 表级配置
│   ├── TableConfig
│   │   ├── tableComment  # 表描述
│   │   ├── className     # 类名
│   │   ├── functionName  # 功能名
│   │   ├── tplCategory   # 模板类型
│   │   ├── treeCode      # 树编码
│   │   ├── subTableName  # 子表名
│   │   └── Map<String, ColumnConfig> columns  # 列级配置
│   │       └── ColumnConfig
│   │           ├── javaType     # Java 类型
│   │           ├── htmlType     # 表单类型
│   │           ├── dictType     # 字典类型
│   │           ├── isInsert     # 是否插入
│   │           └── ...
```
