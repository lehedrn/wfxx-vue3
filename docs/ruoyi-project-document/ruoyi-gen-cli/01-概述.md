# ruoyi-gen-cli 概述

## 1. 项目简介

**ruoyi-gen-cli** 是基于 RuoYi-Vue 代码生成器（ruoyi-generator）二次封装的独立可运行 JAR 包，提供 CLI 命令行方式的代码生成能力。

### 1.1 定位

- **独立运行**：无需 MySQL、Redis 等外部依赖
- **CLI 工具**：通过命令行参数或配置文件控制代码生成
- **DDL 驱动**：直接解析 CREATE TABLE 语句生成代码
- **配置灵活**：支持命令行参数和 YAML 配置文件两种方式

### 1.2 与 ruoyi-generator 的关系

| 特性 | ruoyi-generator | ruoyi-gen-cli |
|------|-----------------|---------------|
| 运行方式 | 内嵌于 RuoYi 应用 | 独立可运行 JAR |
| 数据源 | 需要连接 MySQL | 解析 DDL SQL 语句 |
| 依赖 | 需要 Redis、数据库等 | 仅需 JDK 17+ |
| 使用场景 | 在线代码生成 | 本地批量生成、CI/CD 集成 |
| 配置方式 | 数据库表配置 | 命令行参数 + YAML 配置文件 |

### 1.3 核心特点

1. **零依赖运行**：无需数据库环境，解析 DDL 即可生成代码
2. **批量生成**：支持多个表一次性生成
3. **配置覆盖**：支持命令行参数、YAML 全局配置、YAML 表级/列级配置三层覆盖
4. **主子表支持**：支持单表、树表、主子表等多种模板类型
5. **灵活输出**：支持 ZIP 压缩包或指定目录输出

### 1.4 使用场景

- **本地开发**：快速生成 CRUD 代码框架
- **批量生成**：大量表结构一次性生成代码
- **CI/CD 集成**：自动化代码生成流程
- **离线环境**：无需数据库环境的代码生成

### 1.5 快速示例

```bash
# 简单模式：命令行参数
java -jar ruoyi-gen-cli.jar \
  --sql=create_tables.sql \
  --output=./generated.zip \
  --author=dev \
  --package=com.example.system \
  --prefix=sys_ \
  --web=element-plus

# 配置文件模式：YAML 精细控制
java -jar ruoyi-gen-cli.jar \
  --sql=create_tables.sql \
  --config=gen-config.yml \
  --output=./generated.zip
```

### 1.6 生成的代码结构

生成的代码遵循 RuoYi-Vue 标准分层结构：

```
ruoyi-demo/
├── domain/                 # 实体类
├── controller/             # Controller 层
├── service/                # Service 接口和实现
├── mapper/                 # Mapper 接口
└── resources/mapper/       # MyBatis XML 映射文件
```

### 1.7 支持的模板类型

| 模板类型 | 说明 | 示例 |
|---------|------|------|
| `crud` | 单表 CRUD | 用户管理、部门管理 |
| `tree` | 树表结构 | 部门管理（树形）、菜单管理 |
| `sub` | 主子表 | 订单 - 订单明细、客户 - 商品 |

### 1.8 技术栈

- **运行环境**：Spring Boot 3.x + JDK 17+
- **SQL 解析**：Alibaba Druid SQL Parser
- **模板引擎**：Apache Velocity
- **配置格式**：YAML

### 1.9 项目结构

```
ruoyi-gen-cli/
├── src/main/java/com/ruoyi/gen/cli/
│   ├── GenCliApplication.java    # 主入口类
│   ├── DdlParser.java            # DDL SQL 解析器
│   ├── ConfigLoader.java         # YAML 配置加载器
│   ├── GenTableConfig.java       # 配置模型定义
│   └── CodeGenerator.java        # 代码生成器
├── src/main/resources/
│   └── application.yml           # Spring Boot 配置
└── pom.xml                       # Maven 配置
```
