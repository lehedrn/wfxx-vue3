# ruoyi-gen-cli 配置模板

本文档提供三种模板类型（crud/tree/sub）的完整 YAML 配置模板，可直接复制使用，根据实际需求修改。

## 模板 1：单表 CRUD 配置模板

适用于简单的单表增删改查场景，如用户管理、部门管理、产品管理等。

### 完整模板

```yaml
# ============================================
# 单表 CRUD 配置模板
# 适用场景：简单的单表增删改查
# 示例：用户管理、部门管理、产品管理
# ============================================

# ----- 全局默认配置 -----
global:
  author: dev                              # 作者名
  packageName: com.ruoyi.demo              # 包路径
  moduleName: demo                         # 模块名（默认从 packageName 提取）
  autoRemovePre: true                      # 自动去除表前缀
  tablePrefix: demo_                       # 表前缀（多个用逗号分隔，如：demo_,t_）
  tplCategory: crud                        # 模板类型：crud（单表）
  tplWebType: element-plus                 # 前端类型：element-ui / element-plus
  parentMenuId: 4                          # 上级菜单 ID（在系统中选择父菜单）
  formColNum: 1                            # 表单布局：1 单列 / 2 双列 / 3 三列

# ----- 表级配置 -----
tables:
  # 表名必须与 DDL 中的表名完全一致
  demo_student:
    # 基本信息
    className: Student                     # 实体类名（大驼峰命名）
    functionName: 学生管理                  # 功能名称（菜单显示名）
    functionAuthor: dev                    # 功能作者
    remark: 学生管理模块，支持批量导入导出   # 实体类备注
    businessName: student                  # 业务名（用于前端文件命名，小写）
    
    # 列级配置（按 DDL 中的列名配置）
    columns:
      # ----- 主键字段 -----
      id:
        columnComment: 编号
        javaType: Long
        javaField: id
        isInsert: false                    # 主键通常不插入
        isEdit: false                      # 主键通常不编辑
        isList: true                       # 列表显示
        isQuery: false                     # 不作为查询条件
        
      # ----- 字符串字段 -----
      name:
        columnComment: 学生姓名
        javaType: String
        javaField: name
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true                      # 可查询
        isRequired: true                   # 必填
        queryType: LIKE                    # 模糊查询
        
      # ----- 整数字段 -----
      age:
        columnComment: 年龄
        javaType: Integer
        javaField: age
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        queryType: EQ                      # 等于查询
        
      # ----- 字典字段（下拉选择）-----
      sex:
        columnComment: 性别（0 男 1 女 2 未知）
        javaType: String
        javaField: sex
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        isRequired: true
        queryType: EQ
        htmlType: select                   # 下拉选择
        dictType: sys_user_sex             # 字典类型（确保系统中已存在）
        
      # ----- 字典字段（单选框）-----
      status:
        columnComment: 状态（0 正常 1 停用）
        javaType: String
        javaField: status
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        queryType: EQ
        htmlType: radio                    # 单选框
        dictType: sys_common_status
        
      # ----- 字典字段（开关）-----
      is_delete:
        columnComment: 删除标志（0 存在 1 删除）
        javaType: Boolean
        javaField: isDelete
        isInsert: true
        isEdit: true
        isList: false
        isQuery: false
        htmlType: switch                   # 开关（适用于布尔值）
        dictType: sys_yes_no
        
      # ----- 字典字段（多选框）-----
      hobby:
        columnComment: 爱好（1 钓鱼 2 写作 3 运动 4 冥想 5 音乐 6 电影）
        javaType: String
        javaField: hobby
        isInsert: true
        isEdit: true
        isList: true
        isQuery: false
        htmlType: checkbox                 # 多选框
        dictType: user_hobby
        
      # ----- 日期字段 -----
      birthday:
        columnComment: 生日
        javaType: Date
        javaField: birthday
        isInsert: true
        isEdit: true
        isList: true
        isQuery: false
        htmlType: datetime                 # 日期时间选择器
        
      # ----- 数值字段（Decimal）-----
      balance:
        columnComment: 账户余额
        javaType: BigDecimal
        javaField: balance
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        queryType: BETWEEN                 # 范围查询
        htmlType: input
        
      # ----- 文本字段（多行）-----
      remark:
        columnComment: 备注
        javaType: String
        javaField: remark
        isInsert: true
        isEdit: true
        isList: false
        isQuery: false
        htmlType: textarea                 # 多行文本框
        
      # ----- 审计字段（通常不编辑）-----
      create_time:
        columnComment: 创建时间
        javaType: Date
        javaField: createTime
        isInsert: false
        isEdit: false
        isList: true
        isQuery: false
        
      update_time:
        columnComment: 更新时间
        javaType: Date
        javaField: updateTime
        isInsert: false
        isEdit: false
        isList: false
        isQuery: false
```

### 最小配置

如果只需要快速生成，可以使用最小配置：

```yaml
global:
  author: dev
  packageName: com.ruoyi.demo
  moduleName: demo
  autoRemovePre: true
  tablePrefix: demo_
  tplCategory: crud
  tplWebType: element-plus

tables:
  demo_student:
    className: Student
    functionName: 学生管理
    columns:
      # 只配置需要特殊处理的字段
      sex:
        dictType: sys_user_sex
        htmlType: select
      status:
        dictType: sys_common_status
        htmlType: radio
```

## 模板 2：树表结构配置模板

适用于具有层级关系的树形结构，如部门管理、菜单管理、商品分类等。

### 完整模板

```yaml
# ============================================

# 适用场景：具有层级关系的树形结构
# 示例：部门管理、菜单管理、商品分类
# ============================================

global:
  author: dev
  packageName: com.ruoyi.demo
  moduleName: demo
  autoRemovePre: true
  tablePrefix: demo_
  tplCategory: tree                        # 模板类型：tree（树表）
  tplWebType: element-plus
  parentMenuId: 4
  formColNum: 1

tables:
  # 树表表名必须与 DDL 中的表名完全一致
  demo_category:
    # 基本信息
    className: Category
    functionName: 类别管理
    functionAuthor: dev
    remark: 产品类别管理，支持树形结构展示
    businessName: category
    
    # 树表配置（必须，与 DDL 字段对应）
    treeCode: id                           # 树编码字段（通常是主键）
    treeParentCode: parent_id              # 树父编码字段（指向父节点）
    treeName: category_name                # 树名称字段（显示名称）
    
    columns:
      # ----- 主键字段 -----
      id:
        columnComment: 类别 ID
        javaType: Long
        javaField: id
        isInsert: false
        isEdit: false
        isList: true
        isQuery: false
        
      # ----- 父节点字段（树表核心）-----
      parent_id:
        columnComment: 父类别 ID
        javaType: Long
        javaField: parentId
        isInsert: true
        isEdit: true
        isList: false                      # 列表不显示
        isQuery: false
        
      # ----- 祖级列表（树表核心）-----
      ancestors:
        columnComment: 祖级列表
        javaType: String
        javaField: ancestors
        isInsert: false                    # 自动生成，不需要手动插入
        isEdit: false
        isList: false
        isQuery: false
        
      # ----- 名称字段 -----
      category_name:
        columnComment: 类别名称
        javaType: String
        javaField: categoryName
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        isRequired: true
        queryType: LIKE
        
      # ----- 排序字段 -----
      sort:
        columnComment: 排序
        javaType: Integer
        javaField: sort
        isInsert: true
        isEdit: true
        isList: true
        isQuery: false
        htmlType: input
        
      # ----- 状态字段 -----
      status:
        columnComment: 状态（0 正常 1 停用）
        javaType: String
        javaField: status
        isInsert: true
        isEdit: true
        isList: true
        isQuery: true
        htmlType: radio
        dictType: sys_common_status
        
      # ----- 审计字段 -----
      create_time:
        columnComment: 创建时间
        javaType: Date
        javaField: createTime
        isInsert: false
        isEdit: false
        isList: true
        isQuery: false
        
      update_time:
        columnComment: 更新时间
        javaType: Date
        javaField: updateTime
        isInsert: false
        isEdit: false
        isList: false
        isQuery: false
```

### DDL 要求

树表的 DDL 必须包含以下字段：

```sql
CREATE TABLE demo_category (
  id              BIGINT          NOT NULL      AUTO_INCREMENT COMMENT '类别 ID',
  parent_id       BIGINT          DEFAULT 0     COMMENT '父类别 ID',
  ancestors       VARCHAR(500)    DEFAULT ''    COMMENT '祖级列表',
  category_name   VARCHAR(30)     NOT NULL      COMMENT '类别名称',
  sort            INT             DEFAULT 0     COMMENT '排序',
  PRIMARY KEY (id)
) COMMENT = '产品类别表';
```

### DDL 要求

主子表的 DDL 必须满足：

```sql
-- 主表
CREATE TABLE demo_customer (
  id              BIGINT          NOT NULL      AUTO_INCREMENT COMMENT '客户 ID',
  customer_name   VARCHAR(100)    NOT NULL      COMMENT '客户名称',
  -- ... 其他字段
  PRIMARY KEY (id)
) COMMENT = '客户表';

-- 子表（必须包含外键字段）
CREATE TABLE demo_goods (
  id              BIGINT          NOT NULL      AUTO_INCREMENT COMMENT '商品 ID',
  customer_id     BIGINT          NOT NULL      COMMENT '客户 ID',  -- 外键字段名必须与 subTableFkName 一致
  goods_name      VARCHAR(100)    NOT NULL      COMMENT '商品名称',
  -- ... 其他字段
  PRIMARY KEY (id),
  KEY idx_customer_id (customer_id)  -- 建议添加外键索引
) COMMENT = '商品表';
```

### 注意事项

1. **子表不生成独立代码**：子表的代码会作为主表的一部分生成在同一个 ZIP 文件中，不会单独生成完整的 CRUD 代码。

2. **外键字段命名**：子表的外键字段名必须与 YAML 配置中的 `subTableFkName` 完全一致。

3. **外键索引**：建议为子表的外键字段添加索引，提高关联查询性能。

## 常用字典类型参考

| 字典类型 | 说明 | 选项值 | 适用字段 |
|---------|------|--------|---------|
| `sys_user_sex` | 用户性别 | 0 男 / 1 女 / 2 未知 | sex, gender |
| `sys_common_status` | 通用状态 | 0 正常 / 1 停用 | status |
| `sys_normal_disable` | 通用开关 | 0 正常 / 1 停用 | is_xxx, xxx_flag |
| `sys_yes_no` | 是否 | 0 是 / 1 否 | is_xxx (布尔值) |
| `sys_common_status` | 通用状态 | 0 正常 / 1 停用 | status |

## 常用查询方式参考

| 查询方式 | 说明 | 适用场景 | 示例 |
|---------|------|---------|------|
| `EQ` | 等于 | 精确匹配 | 状态、性别、类型 |
| `LIKE` | 模糊匹配 | 文本搜索 | 姓名、描述、地址 |
| `BETWEEN` | 范围查询 | 日期/数值范围 | 创建时间、价格区间 |
| `GT` | 大于 | 数值比较 | 年龄 > 18 |
| `LT` | 小于 | 数值比较 | 价格 < 100 |
| `GTE` | 大于等于 | 数值比较 | 分数 >= 60 |
| `LTE` | 小于等于 | 数值比较 | 库存 <= 10 |

## 常用表单类型参考

| 表单类型 | 说明 | 适用场景 | 示例 |
|---------|------|---------|------|
| `input` | 单行文本框 | 短文本输入 | 姓名、电话 |
| `textarea` | 多行文本框 | 长文本输入 | 描述、备注 |
| `select` | 下拉选择 | 字典项选择 | 性别、状态 |
| `radio` | 单选框 | 少量选项单选 | 是否、类型 |
| `checkbox` | 复选框 | 多选项多选 | 爱好、标签 |
| `datetime` | 日期时间选择 | 日期时间输入 | 生日、创建时间 |
| `switch` | 开关 | 布尔值切换 | 是否启用 |
| `imageUpload` | 图片上传 | 图片上传 | 头像、封面 |
| `fileUpload` | 文件上传 | 文件上传 | 附件、文档 |
| `editor` | 富文本编辑器 | 富文本内容 | 文章内容 |
