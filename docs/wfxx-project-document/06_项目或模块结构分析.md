## 四、模块职责总结

| 模块 | 职责 | 可移除 |
|------|------|--------|

| ruoyi-framework | Security、配置、AOP、拦截器 | ❌ 不可移除 |

| ruoyi-quartz | 定时任务调度 | ✅ 可移除 |
| ruoyi-generator | 代码生成器（Web） | ✅ 可移除 |
| ruoyi-gen-cli | CLI 代码生成工具 | ✅ 可移除 |
| ruoyi-demo | 示例代码 | ✅ 可移除 |
| ruoyi-base | 设备型号管理（业务模块） | ❌ 业务需要 |
| ruoyi-ui | Vue 3 前端 | ❌ 不可移除 |
