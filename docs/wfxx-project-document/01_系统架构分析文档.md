## 四、登录认证时序图

```plantuml
@startuml 登录认证时序图
skinparam Shadowing false
skinparam defaultFontSize 13

skinparam actorBorderColor #2196F3
skinparam participantBorderColor #2196F3
skinparam participantBackgroundColor #E3F2FD

title 登录认证完整流程时序图

actor "用户" as user
participant "前端 Vue" as fe
participant "CaptchaController" as captcha
participant "SysLoginController" as ctrl
participant "SysLoginService" as login
participant "RedisCache" as redis
participant "AuthenticationManager" as auth
participant "UserDetailsServiceImpl" as uds
participant "SysPasswordService" as pwd
participant "SysPermissionService" as pms
participant "TokenService" as token
participant "AsyncManager" as async

== 1. 获取验证码 ==
user -> fe : 打开登录页
fe -> captcha : GET /captchaImage
captcha -> redis : 生成验证码并存入 Redis\n(key: captcha_code:{uuid})
captcha --> fe : 返回验证码图片 + uuid
fe --> user : 显示验证码

== 2. 提交登录 ==
user -> fe : 输入用户名、密码、验证码
fe -> ctrl : POST /login (LoginBody)

== 3. 验证码校验 ==
ctrl -> login : login(username, password, code, uuid)
login -> redis : 获取验证码 captcha_code:{uuid}
alt 验证码错误
  login --> ctrl : 抛出 CaptchaException
  ctrl --> fe : { code: 604, msg: "验证码错误" }
  fe --> user : 提示错误
end
login -> redis : 删除验证码
login -> login : loginPreCheck() 前置校验\n(用户名/密码长度、IP黑名单)

== 4. 身份认证 ==
ctrl -> auth : authenticate(token)
auth -> uds : loadUserByUsername(username)
uds -> uds : 查询用户(selectUserByUserName)
alt 用户不存在/已删除/已停用
  uds --> auth : 抛出 UserException
  auth --> ctrl : AuthenticationException
  ctrl --> fe : { code: 600, msg: "..." }
  fe --> user : 提示错误
end

== 5. 密码校验 ==
uds -> pwd : validate(user)
pwd -> redis : 获取重试次数 pwd_err_cnt:{username}
alt 超过最大重试次数
  pwd --> uds : 抛出 UserPasswordRetryLimitExceedException
end
pwd -> pwd : BCrypt.matches(password)
alt 密码不匹配
  pwd -> redis : retryCount++
  pwd --> uds : 抛出 UserPasswordNotMatchException
end
pwd -> redis : 清除重试计数

== 6. 权限加载 ==
uds -> pms : getMenuPermission(user)
pms -> pms : 查询角色菜单权限\n(selectMenuPermsByRoleId)
pms --> uds : Set<String> permissions
uds --> auth : 返回 LoginUser(principal)
auth --> login : 认证成功

== 7. 生成 Token ==
login -> token : createToken(LoginUser)
token -> token : 生成 UUID
token -> redis : 存入 LoginUser\n(key: login_tokens:{uuid}, TTL 30min)
token -> token : 创建 JWT (HS512签名)
token --> login : 返回 JWT String

== 8. 记录日志 & 返回 ==
login -> async : recordLogininfor() 异步记录登录日志
login --> ctrl : 返回 AjaxResult(token)
ctrl --> fe : { code: 200, token: "eyJ..." }
fe -> fe : 存储 token (Cookie: Admin-Token)
fe --> user : 跳转到首页

@enduml
```

## 五、权限验证时序图（请求进入）

```plantuml
@startuml 权限验证时序图
skinparam Shadowing false
skinparam defaultFontSize 13

skinparam participantBorderColor #4CAF50
skinparam participantBackgroundColor #E8F5E9

title 请求权限验证流程

actor "前端请求" as fe
participant "JwtAuthenticationTokenFilter" as jwt
participant "TokenService" as token
participant "RedisCache" as redis
participant "SecurityContextHolder" as ctx
participant "Controller" as ctrl
participant "PermissionService(@ss)" as perm

== 1. Token 解析 ==
fe -> jwt : HTTP Request + Authorization: Bearer {token}
jwt -> token : getLoginUser(request)
token -> token : 从 Header 提取 token
token -> token : Jwts.parser().parseClaimsJws(token)
token -> redis : 获取 LoginUser (login_tokens:{uuid})
alt Token 无效/过期/Redis 无缓存
  token --> jwt : null
  jwt --> fe : 401 Unauthorized
end
token -> token : verifyToken(loginUser)\n(不足20分钟自动续期)
token -> redis : 刷新 LoginUser TTL
jwt -> ctx : setAuthentication(loginUser)

== 2. 权限校验 ==
jwt -> ctrl : 请求转发到 Controller
ctrl -> perm : @PreAuthorize("@ss.hasPermi('system:user:list')")
perm -> ctx : getLoginUser()
perm -> perm : 匹配 permissions Set
alt 无权限
  perm --> ctrl : 抛出 AccessDeniedException
  ctrl --> fe : 403 Forbidden
end
perm --> ctrl : 权限通过

== 3. 业务执行 ==
ctrl -> ctrl : 执行业务逻辑
ctrl --> fe : 返回 AjaxResult

@enduml
```
