## 二、核心实体属性详解

### 2.1 SysUser（用户）

**来源**：`com.ruoyi.common.core.domain.entity.SysUser`
**表名**：`sys_user`

| 属性 | 类型 | 数据库字段 | 必填 | 说明 |
|------|------|-----------|------|------|
| `userId` | Long | user_id | 自增 | 用户 ID（主键） |
| `deptId` | Long | dept_id | 否 | 所属部门 ID（外键 → sys_dept） |
| `userName` | String | user_name | 是 | 登录账号 |
| `nickName` | String | nick_name | 是 | 昵称 |
| `email` | String | email | 否 | 邮箱 |
| `phonenumber` | String | phonenumber | 否 | 手机号 |
| `sex` | String | sex | 否 | 性别（0=男, 1=女, 2=未知） |
| `avatar` | String | avatar | 否 | 头像路径 |
| `password` | String | password | 是 | BCrypt 加密密码 |
| `status` | String | status | 是 | 状态（0=正常, 1=停用） |
| `delFlag` | String | del_flag | 是 | 删除标志（0=正常, 2=删除） |
| `loginIp` | String | login_ip | 否 | 最后登录 IP |
| `loginDate` | Date | login_date | 否 | 最后登录时间 |
| `pwdUpdateDate` | Date | pwd_update_date | 否 | 密码最后更新时间 |
| `admin` | Boolean | - | 否 | 是否管理员（transient，不存数据库） |
| `roles` | List\<SysRole\> | - | 否 | 角色列表（关联） |
| `roleIds` | Long[] | - | 否 | 角色 ID 数组（表单用） |
| `postIds` | Long[] | - | 否 | 岗位 ID 数组（表单用） |
| `role` | SysRole | - | 否 | 单个角色（关联查询用） |

**Excel 注解**：用户导出时使用 `@Excel` 注解标记字段

**关联关系**：
- 1:N → sys_user_role
- N:1 → sys_dept

## 五、业务关系

### 5.1 用户权限完整关系图

```
sys_dept (部门树)
    │
    ├──(1:N)──> sys_user ──(1:N)──> sys_user_role ──(N:1)──> sys_role
    │                                                        │
    │                                                        ├──(1:N)──> sys_role_menu ──(N:1)──> sys_menu (菜单树)
    │                                                        │
    │                                                        └──(1:N)──> sys_role_dept ──(N:1)──> sys_dept (数据权限)
    │
    └──(1:N)──> sys_user_post ──(N:1)──> sys_post
```

### 5.2 数据权限生效规则

| dataScope 值 | 名称 | SQL 过滤条件 |
|-------------|------|-------------|
| 1 | 全部数据权限 | 不添加过滤条件 |
| 2 | 自定义数据权限 | `dept_id IN (SELECT dept_id FROM sys_role_dept WHERE role_id = ?)` |
| 3 | 本部门数据权限 | `dept_id = 当前用户部门ID` |
| 4 | 本部门及以下数据权限 | `dept_id IN (SELECT dept_id FROM sys_dept WHERE find_in_set(?, ancestors))` |
| 5 | 仅本人数据权限 | `user_id = 当前用户ID` |

### 5.3 字典关系

```
sys_dict_type (字典类型) ──(1:N)──> sys_dict_data (字典数据)
    │                                      │
    dict_id                                dict_type (外键引用)
    dict_name                              dict_label (显示标签)
    dict_type (唯一标识)                     dict_value (实际值)
```
