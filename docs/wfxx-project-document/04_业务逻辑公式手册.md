# 04 业务逻辑公式手册

## 一、计算公式

### 1.1 密码加密

**公式**：`stored_password = BCrypt.hash(raw_password)`

- 算法：BCrypt（自适应哈希，自带盐值）
- 验证：`BCrypt.checkpw(raw_password, stored_password)`
- 位置：`com.ruoyi.framework.web.service.SysPasswordService`

### 1.2 JWT Token 生成

**公式**：`JWT = Base64(Header) + "." + Base64(Payload) + "." + HMAC-SHA512(Signature)`

- Header：`{"alg": "HS512"}`
- Payload：`{ "login_user_key": uuid, "sub": username }`
- Secret：配置文件 `token.secret`
- 有效期：`token.expireTime` 分钟（默认 30）
- 位置：`com.ruoyi.framework.web.service.TokenService`

### 1.3 Token 自动续期

**条件**：`当前时间 - loginTime >= expireTime / 2`

即距离过期时间剩余不足一半时自动续期，续期后重置 TTL 为完整有效期。

### 1.4 密码重试计数

**公式**：
```
if (retryCount >= maxRetryCount) → 锁定
else → retryCount++
```

- 计数存储：Redis（key: `pwd_err_cnt:{username}`）
- 最大次数：`user.password.maxRetryCount`（默认 5）
- 锁定时间：`user.password.lockTime`（默认 10 分钟）
- 成功登录后清除计数

### 1.5 分页计算

**PageHelper 分页**：
```sql
-- PageHelper 自动追加 LIMIT 子句
SELECT ... FROM table WHERE ... LIMIT offset, pageSize
```

- offset = (pageNum - 1) * pageSize
- 线程安全：PageHelper 在执行后自动清除 ThreadLocal 中的分页参数

### 1.6 Cron 表达式下次执行时间

**公式**：`nextTime = CronExpression.getNextValidTimeAfter(currentTime)`

- 基于 Quartz `CronExpression` 类计算
- 位置：`com.ruoyi.quartz.domain.SysJob.getNextValidTime()`

## 二、校验规则

### 2.1 用户名校验

| 规则 | 值 | 来源 |
|------|-----|------|
| 最小长度 | 2 字符 | `UserConstants.USERNAME_MIN_LENGTH` |
| 最大长度 | 20 字符 | `UserConstants.USERNAME_MAX_LENGTH` |
| 唯一性 | 全局唯一 | `ISysUserService.checkUserNameUnique()` |
| 保留字 | 不允许 "admin" | 业务规则 |

### 2.2 密码校验

| 规则 | 值 | 来源 |
|------|-----|------|
| 最小长度 | 5 字符 | `UserConstants.PASSWORD_MIN_LENGTH` |
| 最大长度 | 20 字符 | `UserConstants.PASSWORD_MAX_LENGTH` |
| 复杂度 | 包含字母和数字 | `SysLoginService.validatePassword()` |

### 2.3 角色键校验

| 规则 | 值 |
|------|-----|
| 唯一性 | `roleKey` 全局唯一 |
| 格式 | 小写字母 + 数字 + 下划线 |

### 2.4 Cron 表达式校验

- 有效性：通过 `CronUtils.isValid(cronExpression)` 校验
- 基于 Quartz `CronExpression.isValidExpression()`

### 2.5 防重复提交

**规则**：同一 URL + 同一参数 + 同一 Token 在 `interval` 毫秒内只允许提交一次

- 存储：Redis（key: `repeat_submit:{token}:{url}`）
- 默认间隔：5000 毫秒
- 位置：`com.ruoyi.framework.interceptor.impl.SameUrlDataInterceptor`

### 2.6 XSS 过滤

**规则**：
- 开关：`xss.enabled`（默认 true）
- 排除：`/system/notice/*`
- 匹配：`/system/*,/monitor/*,/tool/*`
- 过滤：HTML 标签、JavaScript 脚本、事件属性

## 三、业务规则映射

### 3.1 用户状态流转

```
创建 → 正常(0)
         ↓
    停用(1) ← 管理员操作
         ↓
    正常(0) ← 管理员操作
         ↓
    删除(2) ← 逻辑删除（del_flag = '2'）
```

**⚠️ 注意**：用户删除为逻辑删除，数据保留在数据库中

### 3.2 权限继承规则

```
超级管理员（roleKey = "admin"）
  → 拥有所有权限（*:*:*）
  → 不受数据权限限制
  → 绕过 @PreAuthorize 检查

普通用户
  → 通过角色获得菜单权限
  → 通过角色的 dataScope 限制数据可见范围
  → 必须通过 @PreAuthorize 检查
```

### 3.3 菜单类型规则

| menuType | 含义 | 可包含 | 前端行为 |
|----------|------|--------|---------|
| M | 目录 | 子菜单/菜单/按钮 | 不渲染页面，仅作为分组 |
| C | 菜单 | 按钮 | 渲染页面组件 |
| F | 按钮 | 无 | 不显示，仅用于权限标识 |

### 3.4 数据权限生效范围

**⚠️ 隐式决策点**：
```java
// DataScopeAspect 只对标注了 @DataScope 的方法生效
@DataScope(deptAlias = "d", userAlias = "u")
public List<SysUser> selectUserList(SysUser user) {
    // params.dataScope 会被 AOP 自动注入
    return userMapper.selectUserList(user);
}
```

- 管理员角色（admin）不受数据权限限制
- 数据权限通过 Mapper XML 中的 `${params.dataScope}` 拼接实现
- 多个角色时，取最宽的数据范围

### 3.5 定时任务执行策略

| misfirePolicy | 策略 | 说明 |
|---------------|------|------|
| 0 | 默认 | 使用 Quartz 默认策略（立即执行错过的任务） |
| 1 | 立即执行 | 立即执行一次错过的任务 |
| 2 | 执行一次 | 错过后执行一次 |
| 3 | 放弃执行 | 错过则跳过 |

| concurrent | 策略 | 说明 |
|------------|------|------|
| 0 | 允许并发 | 上次未执行完时可触发下一次 |
| 1 | 禁止并发 | 上次执行完前不触发下一次 |

### 3.6 代码生成模板选择

| tplCategory | tplWebType | 生成模板 |
|-------------|------------|---------|
| crud（单表） | element-plus | index.vue（列表页） |
| tree（树表） | element-plus | index-tree.vue（树形列表） |
| sub（主子表） | element-plus | index.vue（含子表编辑） |

**隐式规则**：
- 列名以 `name` 结尾 → 查询方式自动设为 LIKE
- 列名以 `status` 结尾 → 控件类型自动设为 radio
- 列名以 `type`/`sex` 结尾 → 控件类型自动设为 select
- 列名以 `image` 结尾 → 控件类型自动设为 imageUpload
- 列名以 `file` 结尾 → 控件类型自动设为 fileUpload
- 列名以 `content` 结尾 → 控件类型自动设为 editor
- varchar 长度 >= 500 → 控件类型自动设为 textarea

### 3.7 Excel 导出规则

**字典值转换**：
```java
@Excel(name = "用户性别", dictType = "sys_user_sex")
// 导出时：0 → 男，1 → 女，2 → 未知

@Excel(name = "帐号状态", readConverterExp = "0=正常,1=停用")
// 导出时：0 → 正常，1 → 停用
```

### 3.8 通知公告已读规则

- 用户首次打开公告时，自动写入 `sys_notice_read` 表
- 已读标记包含 `notice_id` + `user_id` 组合
- 未读数量通过 `selectCountUnread(userId)` 查询

### 3.9 区划编码规则

- `code` 为区划唯一标识（如 110000 = 北京市）
- `parentCode` 指向父级区划编码
- `level` 标识行政级别（省/市/区县/乡镇/村）
- 支持懒加载树形查询（`listTree(parentCode)`）

## 四、隐藏业务规则清单

### 4.1 字段兼容性转换

| 场景 | 规则 | 来源 |
|------|------|------|
| 密码存储 | BCrypt 加密，明文不可逆 | `SysPasswordService` |
| 性别值 | 0=男, 1=女, 2=未知 | `sys_user.sex` 字典 |
| 状态值 | 0=正常, 1=停用 | 通用状态字典 |
| 删除标志 | 0=正常, 2=删除（无 1） | 通用删除标志 |
| 菜单类型 | M=目录, C=菜单, F=按钮 | `sys_menu.menu_type` |
| 数据范围 | 1~5，含义递增 | `sys_role.data_scope` |

### 4.2 隐式权限校验

| 校验点 | 位置 | 说明 |
|--------|------|------|
| 登录 IP 黑名单 | `SysLoginService.loginPreCheck()` | 登录前检查 IP 是否在黑名单 |
| 用户名/密码长度 | `SysLoginService.loginPreCheck()` | 防止超长输入导致性能问题 |
| 定时任务白名单 | `ScheduleUtils.whiteList()` | 防止任意类被反射调用 |
| 安全校验 | `SysJobController` | 禁止 RMI/LDAP/HTTP(s) 格式的 invokeTarget |
| 防 XSS | `XssFilter` | 过滤请求中的 HTML/JS 内容 |

### 4.3 未文档化的配置开关

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `ruoyi.demoEnabled` | - | 演示模式开关（启用后禁止修改操作） |
| `referer.enabled` | false | 防盗链开关 |
| `xss.enabled` | true | XSS 防护开关 |
| `swagger.enabled` | - | SpringDoc API 文档是否开启 |
| `gen.allowOverwrite` | false | 代码生成是否允许覆盖已有文件 |
| `druid.statViewServlet.enabled` | true | Druid 监控控制台是否开启 |
