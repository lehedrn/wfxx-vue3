# 复杂业务模板

**适用场景**：
- 复杂业务流程/工作流（如多级审批、会签）
- 多状态机流转（如订单状态、项目阶段）
- 跨模块业务协同（如采购 + 入库 + 付款）
- 需要完整文档追溯的大型功能

**文档篇幅**：多文档体系（6 个子文档）

**代码生成支持**：基础代码生成 + 大量手动编写

---

## 文档体系结构

本模板采用多文档体系，按读者角色分离内容：

```
docs/standards/requirement/detail/{module_name}/
├── 01-需求总文档.md        # 项目概述、系统架构、业务全景
├── 02-功能说明.md          # 功能模块详细、依赖关系、优先级
├── 03-界面操作.md          # 页面设计、交互规范、响应式
├── 04-角色权限.md          # 角色定义、权限矩阵、数据权限
├── 05-业务流程和规则.md    # 流程图、状态流转、业务规则
└── 06-数据接口.md          # 数据库设计、API 契约、数据迁移
```

---

## 各文档用途

| 文档 | 主要读者 | 核心内容 | 篇幅 |
|------|---------|---------|------|
| 01-需求总文档 | 项目经理、架构师 | 项目背景、系统架构、业务全景 | 3-5 页 |
| 02-功能说明 | 产品经理、开发 | 功能模块、依赖关系、优先级 | 5-10 页 |
| 03-界面操作 | UI 设计师、前端 | 页面布局、交互规范、响应式 | 5-8 页 |
| 04-角色权限 | 开发、测试 | 角色定义、权限矩阵、数据权限 | 3-5 页 |
| 05-业务流程 | 产品、开发、测试 | 流程图、状态机、业务规则 | 5-10 页 |
| 06-数据接口 | 开发、DBA | DDL、API 接口、MyBatis 映射 | 10-20 页 |

## 使用流程

### 步骤 1：创建文档目录

```bash
mkdir -p docs/standards/requirement/detail/{module_name}/
```

### 步骤 2：复制模板文件

参考 `docs/standards/requirement/detail/` 中的标准模板。

### 步骤 3：填充内容

按文档模板要求，结合具体业务场景填充内容。

### 步骤 4：参考示例

参考 `examples/student/` 完整 6 文档示例（待补充）。
