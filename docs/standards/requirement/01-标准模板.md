## 2. 表结构 (DDL)

### 2.1 单表 CRUD 模板

```sql
-- 表名格式：{业务前缀}_{表名}，如 demo_student
CREATE TABLE {table_name} (
  id              BIGINT          NOT NULL      AUTO_INCREMENT COMMENT '编号',
  -- 业务字段定义
  {field_name}    {field_type}    {constraints} COMMENT '{注释}',
  -- 审计字段（必须）
  create_time     DATETIME        DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_time     DATETIME        DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  create_by       VARCHAR(64)     DEFAULT ''    COMMENT '创建人',
  update_by       VARCHAR(64)     DEFAULT ''    COMMENT '更新人',
  remark          VARCHAR(500)    DEFAULT ''    COMMENT '备注',
  del_flag        CHAR(1)         DEFAULT '0'   COMMENT '删除标志（0 正常 1 删除）',
  -- 索引定义
  PRIMARY KEY (id),
  KEY idx_{field} ({field}) COMMENT '{索引说明}'
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COMMENT='{表注释}';
```

### 2.2 树表模板（Tree）

**适用场景**：部门管理、商品分类、菜单管理等具有层级关系的数据

**必须包含的字段**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | BIGINT | 主键（树编码） |
| `parent_id` | BIGINT | 父节点 ID（树父编码） |
| `ancestors` | VARCHAR(500) | 祖级列表 |
| `{name 字段}` | VARCHAR | 树名称字段 |

```sql
CREATE TABLE demo_category (
  id              BIGINT          NOT NULL      AUTO_INCREMENT COMMENT '类别 ID',
  parent_id       BIGINT          DEFAULT 0     COMMENT '父类别 ID',
  ancestors       VARCHAR(500)    DEFAULT ''    COMMENT '祖级列表',
  category_name   VARCHAR(30)     NOT NULL      COMMENT '类别名称',
  sort            INT             DEFAULT 0     COMMENT '排序',
  status          CHAR(1)         DEFAULT '0'   COMMENT '状态（0 正常 1 停用）',
  create_time     DATETIME        DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_time     DATETIME        DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  create_by       VARCHAR(64)     DEFAULT ''    COMMENT '创建人',
  update_by       VARCHAR(64)     DEFAULT ''    COMMENT '更新人',
  del_flag        CHAR(1)         DEFAULT '0'   COMMENT '删除标志',
  PRIMARY KEY (id),
  KEY idx_parent_id (parent_id)
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COMMENT='产品类别表';
```

### 2.3 主子表模板（Sub）

**适用场景**：订单 - 订单明细、客户 - 商品、文章 - 评论等一对多关系

**主表结构**：
```sql
CREATE TABLE demo_customer (
  id              BIGINT          NOT NULL      AUTO_INCREMENT COMMENT '客户 ID',
  customer_name   VARCHAR(100)    NOT NULL      COMMENT '客户名称',
  phone           VARCHAR(20)                   COMMENT '联系电话',
  create_time     DATETIME        DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_time     DATETIME        DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (id)
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COMMENT='客户表';
```

**子表结构**（必须包含外键字段）：
```sql
CREATE TABLE demo_goods (
  id              BIGINT          NOT NULL      AUTO_INCREMENT COMMENT '商品 ID',
  customer_id     BIGINT          NOT NULL      COMMENT '客户 ID（外键）',
  goods_name      VARCHAR(100)    NOT NULL      COMMENT '商品名称',
  price           DECIMAL(10,2)   DEFAULT 0     COMMENT '价格',
  PRIMARY KEY (id),
  KEY idx_customer_id (customer_id)  -- 建议添加外键索引
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COMMENT='商品表';
```

**注意事项**：
- 子表必须包含外键字段（如 `customer_id`），且类型与主表主键一致
- 建议为子表的外键字段添加索引
- 子表不生成独立代码，作为主表的一部分生成在同一个 ZIP 中

### 2.4 字段规范

| 字段类型 | 命名规范 | 说明 |
|---------|---------|------|
| 主键 | `id` | `BIGINT AUTO_INCREMENT` |
| 布尔/状态 | `is_*`, `status` | `CHAR(1)` 或 `TINYINT(1)` |
| 时间 | `*_time`, `*_date` | `DATETIME` |
| 外键 | `*_id` | `BIGINT` |
| 金额 | `*_price`, `*_amount` | `DECIMAL(10,2)` |

## 3. 代码生成配置 (YAML)

### 3.1 配置文件格式

**文件位置**: `generate/config/{module}/{submodule}/{name}.yml`

**文件命名**: 建议使用 `{业务名}.yml`，如 `student.yml`

```yaml
# ==================== 全局默认配置 ====================
global:
  author: {作者}                         # 作者姓名
  packageName: {包路径}                  # 生成包路径，如 com.ruoyi.demo
  moduleName: {模块名}                   # 模块名（从 packageName 末段提取）
  autoRemovePre: true                    # 自动去除表前缀
  tablePrefix: {前缀}                    # 表前缀，如 demo_
  tplCategory: {模板类型}                # crud / tree / sub
  tplWebType: element-plus               # element-ui / element-plus
  parentMenuId: {菜单 ID}                # 上级菜单 ID（菜单 SQL 执行后获取）

# ==================== 表级配置 ====================
tables:
  {表名}:
    # -- 基本信息 --
    className: {类名}                    # 实体类名（大驼峰）
    functionAuthor: {作者}               # 功能作者（覆盖全局）
    remark: {备注}                       # 备注说明
    
    # -- 生成信息 --
    tplCategory: crud                    # 模板类型
    tplWebType: element-plus             # 前端类型
    packageName: {包路径}                # 包路径
    moduleName: {模块名}                 # 模块名
    businessName: {业务名}               # 业务名（小写）
    functionName: {功能名}               # 功能中文名
    parentMenuId: {菜单 ID}              # 上级菜单 ID
    formColNum: 1                        # 表单列数（1/2/3）
    
    # -- 字段信息（按列名配置） --
    columns:
      {列名}:
        columnComment: {注释}            # 字段注释
        javaType: {类型}                 # Long/String/Integer/Date 等
        javaField: {属性名}              # Java 属性名（小驼峰）
        isInsert: true/false             # 是否插入字段
        isEdit: true/false               # 是否编辑字段
        isList: true/false               # 是否列表字段
        isQuery: true/false              # 是否查询字段
        isRequired: true/false           # 是否必填
        queryType: {查询方式}            # EQ/LIKE/BETWEEN 等
        htmlType: {表单类型}             # input/select/radio/checkbox/datetime
        dictType: {字典类型}             # 关联字典（select/radio/checkbox 用）
```

## 5. 字段配置速查

### 5.1 Java 类型映射

| 数据库类型 | Java 类型 | 示例 |
|-----------|----------|------|
| VARCHAR, CHAR, TEXT | String | name, email |
| BIGINT | Long | id, user_id |
| INT, INTEGER | Integer | age, sort |
| DECIMAL, NUMERIC | BigDecimal | price, amount |
| DOUBLE, FLOAT | Double | score, rate |
| DATE, DATETIME, TIMESTAMP | Date | birthday, create_time |
| TINYINT(1), BIT | Boolean | is_deleted |

### 5.2 表单类型 (htmlType)

| 类型 | 说明 | 适用场景 | 是否需要 dictType |
|------|------|---------|------------------|
| `input` | 单行文本框 | 短文本输入 | 否 |
| `textarea` | 多行文本框 | 长文本输入、备注 | 否 |
| `select` | 下拉选择 | 字典项选择（单选） | **是** |
| `radio` | 单选框 | 少量选项单选（2-4 个） | **是** |
| `checkbox` | 复选框 | 多选项多选 | **是** |
| `datetime` | 日期时间选择 | 日期时间输入 | 否 |
| `imageUpload` | 图片上传 | 图片上传 | 否 |
| `fileUpload` | 文件上传 | 文件上传 | 否 |
| `editor` | 富文本编辑器 | 富文本内容 | 否 |
| `switch` | 开关 | 布尔值切换（0/1） | 否 |

**注意**：
- 使用 `select`、`radio`、`checkbox` 时**必须**配置 `dictType`
- `switch` 适用于布尔值字段（如 `is_deleted`、`status` 等）

### 5.3 查询方式 (queryType)

| 方式 | 说明 | 适用字段 |
|------|------|---------|
| EQ | 等于 | 状态、类型等精确匹配 |
| LIKE | 模糊匹配 | 名称、描述等文本搜索 |
| BETWEEN | 范围查询 | 日期、数值范围 |
| GT/GTE | 大于/大于等于 | 数值范围 |
| LT/LTE | 小于/小于等于 | 数值范围 |

### 5.4 字段配置项

| 配置项 | 说明 | 典型值 |
|--------|------|--------|
| isInsert | 是否插入字段 | true/false |
| isEdit | 是否编辑字段 | true/false |
| isList | 是否列表字段 | true/false |
| isQuery | 是否查询字段 | true/false |
| isRequired | 是否必填 | true/false |

### 5.5 htmlType 和 dictType 使用说明

**htmlType 与 dictType 的关系**：

| htmlType | 是否需要 dictType | 说明 |
|----------|------------------|------|
| `select` | **必须** | 下拉选择，从字典读取选项 |
| `radio` | **必须** | 单选框，从字典读取选项 |
| `checkbox` | **必须** | 复选框，从字典读取选项 |
| `input` | 可选 | 普通输入框，不需要字典 |
| `textarea` | 否 | 多行文本，不需要字典 |
| `datetime` | 否 | 日期选择器，不需要字典 |
| `imageUpload` | 否 | 图片上传，不需要字典 |
| `fileUpload` | 否 | 文件上传，不需要字典 |
| `editor` | 否 | 富文本编辑器，不需要字典 |
| `switch` | 否 | 开关控件，不需要字典 |

**配置示例**：

```yaml
columns:
  # select + dictType（正确）
  sex:
    htmlType: select
    dictType: sys_user_sex     # 系统中必须存在该字典类型
  
  # radio + dictType（正确）
  status:
    htmlType: radio
    dictType: sys_common_status
  
  # checkbox + dictType（正确）
  hobby:
    htmlType: checkbox
    dictType: user_hobby
  
  # input（无需 dictType）
  name:
    htmlType: input
    # 不需要 dictType
  
  # datetime（无需 dictType）
  birthday:
    htmlType: datetime
    # 不需要 dictType
```

**注意事项**：
1. 使用 `select`、`radio`、`checkbox` 时**必须**配置 `dictType`
2. `dictType` 必须是系统中已存在的字典类型
3. 如果字典不存在，生成后会显示为空输入框
4. 字典数据需要预先在 `sys_dict_type` 和 `sys_dict_data` 表中添加

### 7.3 三种模板类型对比

| 特性 | CRUD（单表） | Tree（树表） | Sub（主子表） |
|------|-------------|-------------|--------------|
| **适用场景** | 单表增删改查 | 层级结构数据 | 一对多关系数据 |
| **示例** | 学生管理、商品管理 | 部门管理、商品分类 | 订单 - 订单明细、客户 - 商品 |
| **必填字段** | 标准审计字段 | `id`、`parent_id`、`ancestors`、树名称 | 主表主键、子表外键 |
| **YAML 配置** | `tplCategory: crud` | `tplCategory: tree` + 树字段配置 | `tplCategory: sub` + 子表配置 |
| **树字段配置** | - | `treeCode`、`treeParentCode`、`treeName` | - |
| **主子表配置** | - | - | `subTableName`、`subTableFkName` |
| **前端展示** | 表格列表 | 树形表格 | 主表 + 子表表格 |
| **生成代码** | 标准 CRUD | 树形 CRUD | 主表 CRUD+ 子表操作 |
