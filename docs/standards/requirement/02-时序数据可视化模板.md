## 3. 查询条件设计

### 3.1 查询参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| startTime | Date | 是 | 近 7 天 | 开始时间 |
| endTime | Date | 是 | 当前时间 | 结束时间 |
| granularity | String | 否 | day | 时间粒度：hour/day/week/month |

### 3.2 时序聚合 SQL

```sql
-- 按时间粒度聚合查询示例
SELECT
    {时间分组表达式} AS time_label,
    SUM(value1) AS total_value1,
    AVG(value2) AS avg_value2
FROM {table_name}
WHERE collect_time >= #{startTime}
  AND collect_time <= #{endTime}
GROUP BY {时间分组表达式}
ORDER BY time_label;
```
