## 规范使用原则

1. **强制执行**：所有团队成员必须遵守规范
2. **持续改进**：规范应随项目发展和团队反馈不断更新
3. **工具辅助**：能通过工具自动检查的规范，应集成到 CI/CD 流程中
4. **新人引导**：新成员加入时应首先阅读相关规范

---

## 规范维护

- **负责人**：技术负责人
- **更新频率**：按需更新，每次更新应有明确的变更记录
- **审查流程**：规范修改需经过团队讨论和确认
