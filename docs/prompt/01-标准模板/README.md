## 1. 文档目的

本文档是一套完整的提示词说明书，指导你如何使用 AI 辅助完成**标准模板（CRUD/Tree/Sub）**类型的功能开发。

与直接填写模板不同，这套提示词会**引导你逐步完成**从需求到上线的全过程。

---

## 2. 开发流程概览

标准模板开发分为 **3 个阶段**，AI 会自动引导你完成：

```
┌─────────────────────────────────────────────────────────────────┐
│                    标准模板开发流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  阶段 1  →  阶段 2  →  阶段 3                                   │
│  需求    代码     验证                                           │
│  文档    与集成   与文档                                         │
│  生成                                                           │
│                                                                 │
│  01      02       03                                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 阶段 | 提示词文档 | 主要产出物 | 预计耗时 |
|------|-----------|-----------|---------|
| **阶段 1** | [01-需求文档生成助手.md](./01-需求文档生成助手.md) | 需求文档（含 DDL + YAML） | 10-20 分钟 |
| **阶段 2** | [02-代码生成与集成.md](./02-代码生成与集成.md) | 代码生成命令、菜单 SQL、字典 SQL、拷贝指南 | 5-10 分钟 |
| **阶段 3** | [03-验证与文档.md](./03-验证与文档.md) | 测试清单、API 清单、交互记录 | 5-10 分钟 |

## 3. 核心交互原则

本套提示词遵循**严格的确认机制**：

### 3.1 每步询问

AI 会在每个步骤开始前询问你是否继续。

### 3.2 每步确认

AI 生成的每个产物（需求文档、SQL、配置等）都会等待你确认后才继续。

### 3.3 自动化执行

阶段 2 和阶段 3 中，所有 SQL 和命令执行遵循：
1. AI 展示要执行的命令
2. AI 询问"以上命令是否正确？是否可以执行？"
3. 用户确认后，AI 自动执行
4. AI 展示执行结果

**需要用户手动执行的仅限 UI 操作**：登录系统、浏览器操作、点击"刷新缓存"按钮。

### 3.4 自动流转

阶段完成后，AI 会自动询问是否进入下一阶段，并自动读取下一阶段的提示词。

## 4. 使用说明

### 4.1 开始开发

**步骤 1**: 复制 [01-需求文档生成助手.md](./01-需求文档生成助手.md) 的内容发送给 AI

**步骤 2**: AI 会引导你完成阶段 1，确认需求文档

**步骤 3**: 阶段 1 完成后，AI 会自动询问是否进入阶段 2，确认后自动继续

**步骤 4**: 阶段 2 完成后，AI 会自动询问是否进入阶段 3，确认后自动继续

### 4.2 单独使用某个阶段

你也可以单独使用某个阶段的提示词：

- 如果你已经手写好需求文档 → 直接从 **阶段 2** 开始
- 如果你只需要 AI 帮你写需求文档 → 只使用 **阶段 1**

## 5. 前置条件

在使用本套提示词前，请确保：

### 5.1 环境准备

```bash
# 检查 JDK 版本（要求 17+）
java -version

# 检查 Docker 环境（数据库和 Redis）
docker ps | grep mysql8
docker ps | grep redis8

# 确认项目根目录
cd /home/workspace/com/wfxx-vue3
```

### 5.2 需求明确

- [ ] 已明确功能模块的业务目标
- [ ] 已列出需要管理的核心数据字段
- [ ] 已确认是否有树形结构或主子表关系
