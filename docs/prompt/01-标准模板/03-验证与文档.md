### 步骤 2-2：生成 Playwright E2E 测试脚本（如用户选择）

> **编写 E2E 测试前，请先确认字典的实际 label 值**：
> ```sql
> SELECT dict_label, dict_value FROM sys_dict_data WHERE dict_type = 'sys_common_status';
> ```
> 根据查询结果编写测试脚本中的文本断言，不要假设 label 值（如 `sys_common_status` 的 label 是"成功"/"失败"，而非"正常"/"停用"）。
>
> **参考规范**：
> - 测试编写规范：`docs/standards/test/e2e-testing.md`
> - 脚本开发经验：`docs/lessons/2026-04-07-脚本工具开发总结.md`
>
> **脚本位置**：`scripts/test/e2e/tests/{module}/{business}.spec.js`
>
> **脚本框架**：
> ```javascript
> import { test, expect } from '../../fixtures/auth'
>
> test.describe('{模块名称}', () => {
>   const testData = {
>     {字段 1}: `测试值_${Date.now()}`,
>     {字段 2}: '0',
>   }
>
>   test.beforeEach(async ({ authenticatedPage }) => {
>     await authenticatedPage.goto('/{module}/{business}')
>     await authenticatedPage.waitForLoadState('networkidle')
>   })
>
>   test('新增{模块名称}', async ({ authenticatedPage }) => {
>     // 点击新增按钮
>     await authenticatedPage.click('button:has-text("新增")')
>     
>     // 填写表单
>     // ...
>     
>     // 下拉框选择示例（参考 student.spec.js，使用键盘操作避免渲染延迟）
>     const sexSelect = dialog.locator('.el-form-item:has-text("性别") .el-select').first()
>     await sexSelect.click()
>     await authenticatedPage.waitForTimeout(300)
>     await authenticatedPage.press('body', 'ArrowDown')
>     await authenticatedPage.press('body', 'Enter')
>     await authenticatedPage.waitForTimeout(200)
>     
>     // 提交
>     await authenticatedPage.click('button:has-text("确 定")')
>     
>     // 验证成功
>     await expect(authenticatedPage.locator('.el-message--success')).toBeVisible()
>   })
>
>   // ... 其他测试用例
