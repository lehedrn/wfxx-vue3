## 开发内容

**模块名称**: 区划管理
**模块编码**: system.area
**模板类型**: Tree

## 关键决策

- 模板选择：Tree 树形结构（区划有层级关系）
- 字典设计：sys_area_level（5 级：省/自治区/直辖市、地级市、县/区、乡镇/街道、村/社区）
- 区划编码：根据层级确定长度（2/4/6/9/12 位）
- 索引设计：为 code 和 parent_code 添加索引
- 权限设计：system:area:list/query/add/edit/remove/export
- 树形字段：treeCode=code, treeParentCode=parent_code, treeName=name
- sort 默认值设为 1
- parent_code 默认值设为 '0'（表示根节点）
- Controller 放置在 ruoyi-admin 模块下，其余代码在 ruoyi-system 模块
