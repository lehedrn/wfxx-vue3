# 2026-04-07 编码规范重写

## 背景

用户指出之前创建的编码规范文档与 RuoYi-Vue 3.9.2 项目的实际代码风格不一致，需要参考 `docs/ruoyi-project-document/` 和实际源代码进行重写。

## 问题

初始版本的编码规范文档存在以下问题：

1. **后端规范**：使用了通用的 Spring Boot 命名风格，而非 RuoYi 项目特有的命名约定
2. **前端规范**：使用了通用的 Vue 3 模式，未对齐 ruoyi-ui 的实际代码风格

## 解决方案

### 1. 读取项目文档和源代码

- 读取 `docs/ruoyi-project-document/ruoyi-ui.md` 了解前端项目结构
- 读取实际源代码：
  - `ruoyi-ui/src/views/system/user/index.vue`（系统用户管理页面）
  - `ruoyi-ui/src/views/demo/customer/index.vue`（示例客户管理页面）

### 2. 重写后端编码规范

**docs/standards/coding/backend.md** 主要变更：

| 变更项 | 之前 | 之后 |
|--------|------|------|
| 类命名 | `UserController` | `SysUserController` |
| Service 命名 | `UserService` | `ISysUserService` / `SysUserServiceImpl` |
| Mapper 命名 | `UserMapper` | `SysUserMapper` |
| 响应类型 | 通用 `Response` | `TableDataInfo` / `AjaxResult` |
| 继承关系 | 无 | `extends BaseController` |
| 分页方法 | 通用分页 | `startPage()` + `getDataTable()` |
| 权限注解 | 通用 `@PreAuthorize` | `@PreAuthorize("@ss.hasPermi('')")` |
| 日志注解 | 无 | `@Log(title = "", businessType = BusinessType.X)` |
| 工具类 | 通用工具类 | `StringUtils`, `DateUtils`, `SecurityUtils` |

### 3. 重写前端编码规范

**docs/standards/coding/frontend.md** 主要变更：

| 变更项 | 之前 | 之后 |
|--------|------|------|
| 变量命名 | `users`, `loading` | `userList`, `loading` |
| 查询参数 | `query` | `queryParams` |
| 表单数据 | `formData` | `form` |
| 函数命名 | `loadUsers()` | `getList()` |
| API 导入 | 通用导入 | 具名导入 `listUser`, `getUser` |

| 权限指令 | 无 | `v-hasPermi="['system:user:add']"` |
| 通用组件 | 无 | `pagination`, `right-toolbar`, `tree-panel` |
| 响应数据 | `res.data` | `res.rows` / `res.total` |

### 4. 新增内容

## 代码示例对比

### 后端 Controller

**之前**：
```java
public class UserController {
    @GetMapping("/list")
    public Response list(User user) {
        return Response.success(userService.list(user));
    }
}
```

**之后**：
```java
@RestController
@RequestMapping("/system/user")
public class SysUserController extends BaseController {
    @Autowired
    private ISysUserService userService;
    
    @PreAuthorize("@ss.hasPermi('system:user:list')")
    @GetMapping("/list")
    public TableDataInfo list(SysUser user) {
        startPage();
        List<SysUser> list = userService.selectUserList(user);
        return getDataTable(list);
    }
}
```

### 前端组件

**之前**：
```vue
<script setup>
import axios from 'axios'
const users = ref([])
const loading = ref(false)

async function loadUsers() {
  loading.value = true
  const res = await axios.get('/api/users')
  users.value = res.data
  loading.value = false
}
</script>
```

**之后**：
```vue
<script setup name="User">
import { listUser, getUser } from "@/api/system/user"

const userList = ref([])
const loading = ref(true)

function getList() {
  loading.value = true
  listUser(queryParams.value).then(res => {
    userList.value = res.rows
    total.value = res.total
    loading.value = false
  })
}
</script>
```
