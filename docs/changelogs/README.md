# 交互记录目录

本目录用于记录每次与 AI 的交互内容，便于追踪项目决策过程和变更历史。

---

## 文件命名规范

- 文件名格式：`YYYY-MM-DD.md`
- 示例：`2026-04-07.md`
- 同一天的多次交互记录在同一个文件中

---

## 记录内容

每条记录应包含：

1. **时间**：交互发生的日期
2. **主题**：本次交互的主要议题
3. **变更内容**：具体修改了哪些文件或功能
4. **决策记录**：重要的设计决策和原因
5. **待办事项**：后续需要完成的工作

---

## 文件模板

```markdown
# 交互记录 - YYYY-MM-DD

## 议题 1：[主题名称]

### 背景
[描述背景和问题]

### 讨论内容
[记录讨论过程]

### 决策
[记录最终决策]

### 变更文件
- `path/to/file1.js`
- `path/to/file2.md`

### 待办
- [ ] 待办事项 1
- [ ] 待办事项 2

---

## 议题 2：[主题名称]
...
```

---

## 维护说明

1. 每次 AI 交互后应及时创建或更新对应日期的记录文件
2. 记录应简洁明了，重点突出决策和变更
3. 待办事项应在后续完成并标记
